# 用户角色、权限和资源可见范围

平台采用基于角色的访问控制（RBAC，Role-Based Access Control）机制，对平台管理、数据资产、算法研发与工作流运行实行精细化的权限隔离。

---

## 1. 内置角色体系

平台预置了三类标准角色：

| 角色标识 | 角色名称 | 核心职责与定位 |
| :--- | :--- | :--- |
| `admin` | **系统管理员** | 平台全局运维、用户账号与权限审批、系统配置、回收站数据清理、算子全局默认参数维护。 |
| `developer` | **算法工程师** | 负责算子接入、模型训练调优、算子版本发布申请与复杂工作流模板研发。 |
| `operator` | **业务操作员** | 负责日常管网时序数据接入、数据质量治理流执行、DMA 漏损评估任务运行与结果报告查阅。 |

---

## 2. 核心功能权限矩阵

| 功能模块 / 操作 | 业务操作员 (`operator`) | 算法工程师 (`developer`) | 系统管理员 (`admin`) |
| :--- | :---: | :---: | :---: |
| **数据源接入与 CSV 上传** | ✅ 读写 | ✅ 读写 | ✅ 读写 / 全局管理 |
| **数据质量治理与派生版本发布** | ✅ 运行与发布 | ✅ 运行与发布 | ✅ 全量管理 |
| **算子目录与契约浏览** | ✅ 查看 | ✅ 查看 | ✅ 查看 |
| **算子默认参数在线调整** | ❌ 无权 | ❌ 无权 | ✅ 专属配置与发布 |
| **工作流草稿编辑与发布** | ✅ 个人私有/共享 | ✅ 全量编辑 | ✅ 全量管理 |
| **工作流执行与任务查看** | ✅ 执行与本人记录 | ✅ 执行与本人记录 | ✅ 全局审计与取消 |
| **用户管理与权限分配** | ❌ 无权 | ❌ 无权 | ✅ 专属管理 |
| **回收站恢复与永久清除** | ❌ 仅个人软删除 | ❌ 仅个人软删除 | ✅ 全局恢复与清空 |

---

## 3. 资源可见性与隔离原则

1. **私有资源与团队共享**：
   - 用户创建的数据资产草稿与工作流草稿默认归属于创建者本人；
   - 工作流发布为公共模板后，对同工作空间内的其他成员可见并支持克隆；
2. **审计与操作可追溯**：
   - 所有的登录、数据导入、工作流发布、任务取消与参数修改均在系统审计日志中记录操作者 `user_id` 与时间戳；
3. **敏感凭据隔离**：
   - 外部数据库密码、API Token 仅保存在服务端加密存储中，前端与文档界面永不回显明文。
