# 训练并使用季节稳健异常检测模型

针对具有日周期或周周期的监测数据，可以训练一个按数据集拟合的季节稳健异常检测模型。训练结果需要经过状态检查和发布流程，文档不对精度或业务效果作保证。

## 前置条件

需要训练权限和一个已经准备完成的数据版本。建议选择覆盖多个完整周期、且业务人员确认可用于训练的历史数据。Chronos-2 是预训练推理算法，不在此向导中训练。

## 操作步骤

1. 打开【算子中心】，选择【季节稳健基线异常检测】，再进入【训练与模型】。
2. 在训练卡片的数据选择器中选择已准备好的数据资产版本、点位、指标和值来源，确认时间范围覆盖足够的完整周期。
3. 设置【季节性】（自动判断、日周期或周周期）、【最少周期】和【MAD 下限】，然后点击【开始在线训练】。
4. 在页面看到训练任务已提交后，到【任务中心】查看这次训练的任务记录和排队、运行、完成或失败状态；训练页的【查看训练任务记录】也会打开该记录。
5. 训练完成后，在同一【训练与模型】页的模型资产列表确认模型为【就绪】。需要在工作流中使用时，再按已有发布或工作流配置权限选择模型。

## 结果与失败处理

训练完成只表示模型资产已生成，不代表算法已发布或检测结论已验证。数据周期不足、参数不合法或任务取消时，按错误提示修正数据或参数后重新发起训练。模型默认按私有方式管理；需要共享时由拥有者或管理员调整可见性。
