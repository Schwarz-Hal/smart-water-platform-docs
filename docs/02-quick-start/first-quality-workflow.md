# 从上传 CSV 到运行第一个质量分析工作流

## 前置条件

- 已登录平台，并具有上传数据和运行工作流的权限。
- CSV 不超过页面提示的大小限制，且包含时间列、点位列和至少一个数值指标列。

## 操作步骤

1. 进入“数据源与导入”，点击“上传 CSV”。填写“数据资产名称”并选择文件；页面支持 UTF-8、UTF-8 BOM 和 GB18030 编码。
2. 文件预览后，在“字段预览与映射”中选择“点位列”和“时间列”。“记录 ID 列（可选）”可留空，留空时平台按文件和行生成记录标识。
3. 在指标映射中为每个指标填写“指标代码”“显示名称”“单位”，并选择“原始值列”。“修复值列（可选）”和“状态列（可选）”按文件实际情况选择。
4. 如需导入完成后立即生成质量评分，勾选“导入完成后自动质量评分”，然后点击“确认映射并导入”。提交会创建不可变的数据版本；等待该版本进入可用状态。
5. 在数据资产的“详情与治理”中点击“创建治理工作流”，或进入“工作流”新建并选择内置的“整份数据质量评估”结构。前者使用“时序数据治理（基础版）”，会在质量评估之外继续进行治理并发布派生版本；后者只运行 `dataset_asset_v1` 加 `data_quality_profile_v1`，不修改原数据。
6. 在编辑器选中数据资产节点，在“节点属性”的“运行数据绑定”中绑定刚导入的数据版本。质量画像结构只需绑定 `dataset`；若使用通道节点，则按页面要求绑定对应的数据集、点位和指标。
7. 点击“保存草稿”，再点击“校验图”。校验通过后点击“发布版本”，然后点击“运行已发布版本”。
8. 在运行详情查看运行状态、节点结果和最终输出；打开质量报告查看等级、分数及各质量维度。

## 结果与失败处理

“整份数据质量评估”输出质量报告；“时序数据治理（基础版）”输出治理前报告、治理后报告和派生数据版本。原始数据版本保持不变。

如果字段映射校验失败，返回上传预览修正时间、点位或指标列后重新提交。若工作流校验失败，按节点属性和端口提示补全绑定、连接或参数；未保存草稿不能由后端校验。运行失败时进入运行详情查看失败节点和日志，修正草稿后重新保存、校验并发布新版本。

## 参考资料

本流程使用平台内置的数据资产导入、质量画像和基础治理结构；页面显示的字段与输出以当前版本为准。
