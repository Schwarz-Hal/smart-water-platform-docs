# C2 形态—关系一致性多证据异常检测

## 用途与定位

C2 对每个设备的流量和压力窗口融合三类证据：时序形态、设备间关系一致性和历史规则先验。它输出窗口级异常分数、异常类型候选及基于推断关系的诊断路径候选。

当前没有真实管网拓扑、设备类型、运行日志或人工异常类型标签。因此拓扑由训练集相关性推断，原因路径和类型都是诊断候选，不是已核验的根因或现场关系。与 C1 一样，模型训练不读取真实标签，但验证集 Best-F1 阈值使用传感器有效性标签。

## 方法原理

### 形态与关系特征

对每个 96 点二维流压窗口，形态特征对每个通道计算均值、标准差、低频谱能量、高频谱能量、线性斜率和滞后 1 点自相关，拼接后由 MLP 编码。

关系输入包含六类量：流量与拓扑上下文的质量一致性、当前点相对上一点的时间变化（流量和压力两维）、当前点与拓扑上下文的差异（两维）、流量—压力耦合相关性差异。流量—压力相关性使用中心化协方差除以两通道标准差的形式：

$$
\rho(x)=\frac{mean((x_0-\bar{x}_0)(x_1-\bar{x}_1))}
{\sqrt{mean((x_0-\bar{x}_0)^2)mean((x_1-\bar{x}_1)^2)+10^{-6}}}
$$

### 训练集相关性拓扑

对每个设备先按训练数据标准化，再计算其与其他设备在流量、压力上的 Pearson 相关系数。按两通道相关系数绝对值的平均值选择最多 `topology_neighbors` 个邻居，并按各通道相关系数绝对值归一化为上下文权重：

$$
topology_d(t)=\sum_{k\in N(d)}w_{d,k}\,z_k(t)
$$

这是一种训练数据关系代理，不是物理管线连接表；验证和测试数据只使用已经构造好的训练关系。

### 多证据融合与异常分数

形态编码、关系编码和历史规则先验融合成 evidence 向量。模型分别计算形态重构误差、关系特征重构误差和历史预测/先验误差，形成：

$$
c_t=[e_{morphology,t},e_{relation,t},e_{history,t}]
$$

权重网络经 softmax 得到 $w_t$，三项和为 1。训练时使用重构、一步预测、关系重构、历史先验、正常分数和权重平衡损失。评分阶段沿用 Top-K 正常证据记忆，以局部均值/方差对各分量进行非负标准化后计算：

$$
s_t=\sum_jw_{t,j}\max\left(\frac{c_{t,j}-\bar{c}_{t,j}}
{\sqrt{v_{t,j}+10^{-4}}},0\right)
$$

窗口包含原始缺失观测时，输入使用因果前向填补并保留掩码，最终分数使用训练参考分数上界加 10 倍训练分数离散度的固定值。

### 类型候选与诊断路径

训练时从正常窗口合成五类扰动：`point_spike`、`level_shift`、`trend_drift`、`relation_break`、`sensor_dropout`，用合成类型标签训练 Softmax；真实数据没有这五类的人工真值，所以类型概率不是有监督分类准确率。

若窗口被判为异常，路径搜索将形态、关系和历史规则证据按可靠度加权：

$$
Score(path)=\sum_iw_i r_i
$$

关系证据占优时，路径可经过相关性邻居；缺失时会优先给出传感器掉线候选。路径中的责任节点、邻居和建议是解释候选，不能证明真实根因、拓扑或处置必要性。

## 输入与输出

训练集按设备提供修复后的 `flow`、`pressure` 和时间序列，不使用真实异常标签；验证集和测试集提供原始流量、压力以及 `flow_label`、`pressure_label`，用于阈值选择和最终评估。输入同时需要训练集构造的设备关系上下文和日/周时间特征，窗口长度默认 96。

输出包括窗口末端异常分数、设备专属 Best-F1 阈值、异常预测、形态/关系/历史证据及权重、Top 类型概率、邻居信息和缺失标记。异常候选还可输出根因路径、责任节点、路径分数和建议；这些字段均为诊断候选。

## 训练与模型

模型按设备独立训练，核心包括 GRU、形态特征 MLP、关系编码器/解码器、历史规则 MLP、证据融合层、类型分类器和自适应权重 MLP。训练在正常窗口上使用带噪重构、预测和关系一致性目标，并额外使用合成扰动类型的交叉熵；正常 holdout 用于早停。

默认最多 30 个 epoch、patience 5，并为每个设备建立最多 1024 个正常参考样本的 Top-K 记忆。拓扑邻居默认取 2 个，类型候选默认返回前 3 类。

## 参数

| 参数 | 默认值 | 说明 |
| --- | ---: | --- |
| `window_length` | `96` | 历史窗口长度，至少为 `8`。 |
| `batch_size` | `256` | 训练批大小。 |
| `hidden_size` | `64` | GRU 和 MLP 隐藏宽度。 |
| `morphology_size` | `32` | 形态表征宽度。 |
| `relation_size` | `16` | 关系表征宽度。 |
| `evidence_size` | `48` | 融合证据宽度。 |
| `num_anomaly_types` | `5` | 合成异常类型数量。 |
| `top_types` | `3` | 输出的类型候选数量，不能大于类型总数。 |
| `topology_neighbors` | `2` | 每设备训练集相关性邻居数。 |
| `noise_std` | `0.03` | 训练输入噪声标准差。 |
| `synthetic_scale` | `2.0` | 合成扰动幅度基准。 |
| `train_validation_ratio` | `0.15` | 训练数据尾部 holdout 比例。 |
| `reference_size` | `1024` | 正常证据记忆最大样本数。 |
| `top_k` | `32` | 每个窗口使用的最近正常参考数，必须小于 `reference_size`。 |

## 结果解释

异常分数反映当前窗口相对设备正常记忆的形态、关系和历史证据偏离。类型概率表示模型在合成扰动类别上的匹配候选；邻居、责任节点、路径分数和建议表示解释路径，不是实测拓扑或人工确认原因。

## 适用范围

适用于多设备流量/压力时序的离线异常筛查、关系一致性研究和解释候选生成，前提是训练集可代表正常状态并且设备时间戳已对齐。适合同时查看点级、事件级和解释字段。

## 限制与注意事项

- 拓扑由训练集相关性推断，不能替代真实管网拓扑；相关设备不等于存在因果路径。
- 类型 Softmax 使用合成扰动自监督训练，当前没有真实类型标签，不能报告真实类型分类准确率。
- 模型参数训练不使用标签，但验证集 Best-F1 阈值依赖传感器有效性标签；完整流程并非完全无标签。
- `flow_label`、`pressure_label` 是传感器有效性标签，不是漏损标签；C2 不证明漏损或根因。
- Point Adjustment 只在评估阶段用于事件指标，不能修改原始分数或制造运行时告警闭环。
- 缺失观测的输入填补与固定高分处理用于建模和评估，不是对真实传感器值的恢复。

## 评估指标

评估报告按整体和设备报告 Point Adjustment 前后 Precision、Recall、F1、AUROC，以及按设备事件计算的 Affiliation-Precision、Affiliation-Recall、Affiliation-F1。类型输出只提供候选概率和计数，不使用真实类型标签计算分类准确率。
