# B1 非平稳时频协同多变量预测

## 用途与定位

B1 对每个设备的流量和压力联合建模，用过去 96 个采样点直接预测未来 12 个采样点。模型把时域趋势、频域结构和窗口内的潜在工况共同用于预测；“潜在工况”是模型学习的状态，不等同于降雨、潮汐或调度类别。

本文描述实验模型和评估口径，不把实验输出解释为生产可用性、漏损结论或业务准确率。

## 方法原理

### 归一化与潜在工况

训练集按设备分别计算流量、压力的均值和标准差，并用于各数据划分。对输入目标 $x$，ReVIN 在每个窗口内计算：

$$
\tilde{x}_{t,j}=\gamma_j\frac{x_{t,j}-\mu_j}{\sigma_j+\epsilon}+\beta_j
$$

其中 $\mu_j$、$\sigma_j$ 是窗口统计量，$\gamma_j$、$\beta_j$ 是可学习仿射参数，预测头输出后使用同一窗口统计量逆变换。工况识别器根据窗口均值、标准差、首尾变化和一阶差分波动生成 logits，并通过 softmax 得到潜在工况分布。

### 时频分支与融合

- 多尺度移动平均使用 5 点和 25 点窗口的平均结果表示趋势。
- 时域分支先经过因果空洞卷积残差块，再经过 Transformer 编码器。
- 频域分支对归一化目标在尺度 1、2、4 上做实数快速傅里叶变换（RFFT），将实部、虚部、归一化频率和低/高频带标识编码后交给自注意力。
- 交叉注意力以时域状态为 Query、频域状态为 Key/Value。最后的时域摘要、频域摘要和设备嵌入经 sigmoid 门控融合，再由多步预测头输出。

联合训练目标为：

$$
L=L_{pred}+\lambda L_{freq}+\eta L_{state}
$$

其中 $L_{pred}$ 是标准化空间中的预测 MSE；$L_{freq}$ 是预测与真实序列 `log1p(|RFFT|)` 的 MSE；$L_{state}$ 由完整窗口与近期半窗口工况分布之间的双向（对称）KL 一致性项，以及批次工况分布平衡项组成。实现将平衡项乘以 `0.1` 后与一致性项相加；两者都不是工况标签监督。

## 输入与输出

输入按设备和时间排序，必须提供 `device_id`、`record_time`、`flow`、`pressure`。每个样本的历史输入为 96 点、8 个特征：流量、压力以及由时间生成的日、周、年周期正余弦特征；目标为未来 12 点的二维 `[flow, pressure]`。

输出为形状 `[12, 2]` 的流量和压力点预测，并保留设备、预测时间和窗口信息。实验结果还可输出潜在工况概率、主导工况、时域/频域融合状态等诊断特征。

训练数据使用修复后的流量和压力序列；验证集和测试集通过时间顺序构造窗口，前一划分末尾只作为历史上下文，不作为当前划分的预测目标。

## 训练与模型

模型主要组件为 ReVIN、多尺度移动平均、潜在工况识别器、因果空洞 TCN、Transformer、三尺度频域 Transformer、交叉注意力、设备嵌入和直接多步预测头。默认每个设备共享模型参数，同时使用设备嵌入区分设备。

训练使用 AdamW、梯度裁剪、验证集早停和固定随机种子。实验默认最多 50 个 epoch，连续 8 个 epoch 验证损失无改善时提前停止；训练、验证和测试窗口数量以实际输入数据为准。

## 参数

| 参数 | 默认值 | 说明 |
| --- | ---: | --- |
| `input_length` | `96` | 历史上下文点数。 |
| `horizon` | `12` | 直接预测的未来点数。 |
| `batch_size` | `256` | 训练批大小。 |
| `hidden_size` | `128` | 时频编码器的隐藏宽度。 |
| `num_layers` | `2` | TCN/Transformer 分支层数。 |
| `attention_heads` | `4` | 注意力头数；隐藏宽度必须可被其整除。 |
| `device_embedding_dim` | `16` | 设备嵌入维度。 |
| `num_regimes` | `4` | 潜在工况类别数量。 |
| `dropout` | `0.2` | Dropout 比例，取值范围为 `[0,1)`。 |
| `learning_rate` | `0.001` | AdamW 学习率。 |
| `weight_decay` | `0.00001` | AdamW 权重衰减。 |
| `epochs` | `50` | 最大训练轮数。 |
| `patience` | `8` | 验证损失早停耐心轮数。 |
| `frequency_loss_weight` | `0.1` | $L_{freq}$ 权重。 |
| `state_loss_weight` | `0.01` | $L_{state}$ 权重。 |

## 结果解释

预测值与输入流量、压力使用相同的物理变量，但模型训练和指标计算在每设备标准化空间完成。潜在工况概率、频域状态和融合门控用于解释模型内部状态，不能直接命名为某种外部工况。预测步数越远，结果应结合按步指标和输入数据质量阅读。

## 适用范围

适用于具有稳定设备标识、时间顺序和流量/压力历史的多设备短期联合预测实验。适合比较时域、频域和多变量融合设计，不适合作为未经验证的现场控制或漏损判断依据。

## 限制与注意事项

- 当前输入主体只有流量和压力；模型接口中的辅助信息不等于实验数据已经包含降雨、上下游状态、潮位或边界字段。
- 输入长度和预测长度的默认契约是 96 和 12；改变它们需要同时确认窗口构造、模型头和评估结果。
- 每设备标准化参数只应由训练数据拟合；不同设备或不同采样周期的指标不能直接混比。
- 预测、潜在工况和频域状态都是模型输出，不构成漏损、故障或因果结论。

## 评估指标

实验以每设备标准化空间中的联合流量/压力结果计算，并按整体、设备和预测步分别报告：

- MAE：$|\hat{y}-y|$ 的平均值；
- RMSE：$\sqrt{mean((\hat{y}-y)^2)}$；
- $R^2$：$1-\frac{\sum(\hat{y}-y)^2}{\sum(y-\bar{y})^2}$，分母过小时使用实现中的数值保护。

这些指标描述该实验数据划分上的预测误差，不代表其他设备、时间范围或生产环境的效果。
