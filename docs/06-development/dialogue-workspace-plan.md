# 对话驱动工作台实施计划

## 用途与权限

本计划将平台的主要入口调整为左侧对话、右侧工作区。用户在对话中提出目标、附加资料并确认操作；数据查看、流程编排和结果展示继续使用现有组件。文件管理、算法、扩展和既有项目入口保留。

开发从 `baseline-2026-11-04` 建立的 `feature/dialogue-workspace` 分支开始。首批采用预设对话和既有 LeakDB 分析结果，目标是验证完整交互；不接入大模型，不上传附件，不创建计算任务，不改变后台接口、账号权限或数据库。本轮只作本地展示，部署和合并另行确认。

本文为实施与验收依据。验收项保持待检查状态；完成情况须由协调者根据实际代码和检查记录更新，不将预设演示登记为真实智能体能力。

2026-11-05 保存当前开发检查点：对话入口、配套资料校验、步骤输入输出查看和固定结果回放已有本地实现；用户评审要求重新安排分析工作台布局，该重排尚未实施。现有定向测试与局部页面检查不等同于本清单全部验收通过。下一阶段优先推进算法中心试用闭环，本文保留后续对话工作区的实施依据。

## 总体路线

| 批次 | 主要交付 | 完成边界 |
| --- | --- | --- |
| 第一批 | LeakDB 预设对话、资料读取、数据展示、流程调整、确认操作与结果回放 | 使用固定资料和既有结果，完成本地交互演示 |
| 第二批 | 数据中心列表、质量评分、推荐治理与处理前后对比；准备 L-Town 资料 | 核实数据情况并明确分区含义，不预设分区算法已经具备 |
| 第三批 | 数据专家工具 | 查询授权资料、读取质量报告，经用户确认后执行治理 |
| 第四批 | 算法选择、流程专家及首页统筹 | 生成、修改、校验并执行真实 DAG，根据真实结果回答 |

后续批次沿用现有权限、资源版本和运行追溯机制。算法扩展仍通过 SDK、受控环境和扩展生命周期接入，不开放无限制代码执行。

## 首批请求与输入

首页暂时隐藏十二任务选择，直接显示对话入口。示例目标为“分析这一批数据并汇总漏损情况”。用户可选择或拖入配套 LeakDB 文件夹、ZIP，也可点击“使用演示资料”。发送前允许移除或替换附件，显示资料名称、文件数量和读取状态。

文件夹和 ZIP 使用同一份资料，附带固定清单，记录文件角色、版本及内容摘要。浏览器在本地核对清单、必需文件与摘要；不建立个人空间资源。单文件上限为 16 MiB，文件合计及 ZIP 文件本身上限为 32 MiB，条目最多 16 个。ZIP 仅支持 STORE 和 DEFLATE，拒绝嵌套压缩包、加密内容及异常路径。不实现任意压缩包导入，也不执行附件中的代码。

会话内保存附件、消息、当前阶段、流程草稿和结果。刷新页面回到初始状态；切换资料、重新开始或离开页面时取消尚未完成的读取及演示步骤。

## 首批响应与交互

### 资料识别与数据查看

发送后，左侧依次显示简短的分析步骤：整理管网、观测及参考资料；核对点位、管段与传感器关联；准备多源协同漏损检测流程。步骤可收起，名称、数量和检查状态均来自已校验资料，不展示冗长的模拟推理。预设步骤之间分别停留 1.8 秒和 2.1 秒，用于阅读与展示衔接；这不是后台任务进度，实际文件校验不由该节奏判定完成。

右侧同步展开完整管网和传感器数据。同一组资料使用一张资料入口卡；选中点位只更新详情和关联曲线。数据浏览阶段不显示检测告警。

### 流程建议与调整

对话中提供“多源协同漏损检测”流程卡，包含实际演示 DAG 的缩略图、简短摘要以及“调整流程”“执行分析”。点击“调整流程”后，右侧展开现有编辑器，数据预览收缩保留；对话和输入框持续存在。

缩略图中的节点可直接点选，也可通过键盘 Enter 或 Space 打开步骤详情。右侧详情将输入和输出分开列出，根据内容显示原始记录样本、正常参考模型摘要、拓扑明细、检测曲线或完整管网结果入口。输入卡可追溯上游步骤，关闭详情后返回原工作区视图。确认回放前，参考模型、拓扑处理和检测输出只显示预期输出提示，不提前展示计算结果。

流程卡后询问：“流程已准备好。可以直接执行，也可以告诉我需要调整的部分。”首版支持以下预设交互：

- 查看类指令切换对应数据视图，例如“先看看压力数据”。
- 调整类指令打开流程编辑器或参数面板，例如“调整流程”“修改参数”。
- 确认类指令与执行按钮一致，例如“执行”“开始分析”。
- 未匹配的修改请求引导用户在右侧调整流程，不回复未发生的修改结果。

编辑器使用一份草稿。移动节点和调整区域布局不改变执行配置；参数、节点或连线等执行配置变化后，主操作改为“播放已有结果”，并提供“恢复演示流程”。恢复由用户主动触发，不悄悄覆盖修改。

### 结果回放

确认后展示简短的回放状态，进入现有分析工作台：左上为流程概览，右上为完整管网，下方为关联曲线及综合结果。沿用平滑增长曲线、默认收起时间轴、自动播放、暂停以及疑似漏损点提示。

结果通过专用演示适配器读取，不伪造任务编号、服务器日志或计算状态。对话摘要、管网标记、数量和时间范围使用同一份结果；对话中的“漏损情况汇总”卡可点击，重新打开结果工作区。用户可回到资料、调整流程或重新播放，保留当前点位、视角和对话记录。

界面保留简短的“演示预览”标识，不在每条消息中重复解释演示边界。

## 组件与界面安排

新增独立对话工作区容器，拆分消息展示、附件识别、演示步骤、流程卡及面板切换职责。复用管网工作区和现有 DAG 画布，不增加第二套编辑器或结果引擎。首次使用后保留组件实例，隐藏面板不接受焦点和快捷键。

沿用当前蓝白界面。左侧对话默认约占三分之一，右侧占其余空间，分隔条支持调整；统一标题栏、圆角、边界和留白，避免流程缩略卡内再套重复标题。使用现有可中断动效；减少动态效果设置下直接切换。只检查桌面布局，不增加手机适配。

实施顺序为：整理资料、DAG 与既有结果；完成对话及附件入口；接入数据展示；接入流程卡和编辑器；接入回放与摘要；最后逐阶段检查界面并更新使用说明。

前端 `scripts/prepare-dialogue-demo.mjs` 从既有工作区样例生成配套资料包和本地预览。可选的已验证输出目录用于核对输入摘要及读取参考模型等派生预览。资料和模型摘要留在被忽略的 `public/local-preview` 及本机交付目录，不纳入 Git。

## 错误与重试

- 没有附件时保留目标输入，引导选择资料，不生成检测结论。
- 资料缺失、摘要不匹配或 ZIP 损坏时显示具体问题，允许替换，不套用演示结果。
- 重复发送或点击执行不启动重复步骤；操作期间保留可理解的状态。
- 中途更换资料或重新开始后，旧异步响应不得写入新会话。
- 数据、流程或结果资源读取失败时保留已完成内容，提供重试，不以倒计时标记成功。
- 修改流程后仍可回放原结果，但不把它作为新配置的计算结果。

## 演示操作步骤

以下步骤作为首批完成后的演示脚本，交付前须逐项核对。

1. 打开首页，输入“分析这一批数据并汇总漏损情况”。
2. 附加配套文件夹或 ZIP，或选择“使用演示资料”，读取完成后发送。
3. 查看右侧完整管网，选中点位查看关联传感器曲线。
4. 查看对话中的流程卡，点击节点查看输入与预期输出；点击“返回工作台”关闭详情。
5. 点击“调整流程”进入右侧流程编排。保持演示配置并点击“执行分析”，或输入“开始分析”。
6. 在分析工作台查看告警与增长曲线，使用暂停、回放及点位选择操作。
7. 再次点击流程节点，查看对应的输入样本、输出摘要或检测曲线，必要时追溯上游；点击“漏损情况汇总”卡回到结果。
8. 返回调整流程；如改变执行配置，可播放已有结果或主动恢复演示流程。

## 验收清单

- [ ] 文件夹、ZIP 和快捷资料入口显示一致的资料与结果。
- [ ] 无附件、错误资料、损坏 ZIP、重复发送和中途替换资料均有明确处理。
- [ ] 数据、编排和结果在同一界面完成，对话保持连续。
- [ ] 流程缩略图与 DAG 一致；执行配置变化后不把旧结果表现为新计算结果。
- [ ] 操作不产生服务器上传、个人空间资源或后端计算任务。
- [ ] 点位、曲线、告警和对话摘要来自同一组资料及结果。
- [ ] 流程节点可用鼠标和键盘打开详情，输入可追溯上游；关闭后恢复原视图，回放前不提前展示派生输出。
- [ ] 对话中的“漏损情况汇总”卡可以重新打开结果工作区。
- [ ] 组件切换保留编辑和查看状态，销毁时清理计时器、监听和异步读取。
- [ ] 在 1366×701、1920×1080 检查长文件名、对话滚动、输入框、面板边界、键盘焦点和动画中断。
- [ ] 只运行附件识别、演示状态和工作区衔接的定向测试，不重复全量测试。

首批交付包括本地可操作演示、配套资料文件夹和 ZIP、实施计划及演示步骤。原始资料、结果制品和检查截图留在本机交付目录，不写入代码仓库。L-Town、真实模型调用、专家协作及任意代码上传不纳入首批。
