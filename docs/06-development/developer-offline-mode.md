# 开发者离线调试模式

## 用途

开发者离线模式用于在本机检查前端页面的空数据、延迟、错误、任务进度和角色显示。它是视觉与交互调试工具，不是产品运行环境，也不代表真实数据、算法结论或服务可用性。

## 启动与前置条件

在前端项目目录运行：

```text
npm run start:offline
```

开发服务器使用 `developer-offline` 配置，并在 `http://localhost:4201` 提供页面。模式只允许从本机地址启动。启动后自动进入模拟管理员，可在工具条切换身份，无需真实账号密码。

首次使用前，如依赖尚未准备好，需要联网完成一次依赖安装；依赖安装完成后，离线启动不需要后端服务或网络连接。

## 角色、状态与延迟工具条

页面顶部的开发者工具条可以切换：

- 角色：管理员、普通用户或访客。角色只用于检查权限显示和空白状态。
- 数据状态：正常、空数据、加载中或模拟错误。
- 任务状态：排队、运行中、成功、失败或已取消。
- 训练阶段：准备、训练、校准或保存。
- 响应延迟：150 ms 或 2000 ms。

切换状态会重新加载页面，并清除离线会话、任务焦点和工作流草稿缓存。加载中状态保持请求未完成；错误状态返回模拟错误，便于检查失败提示和重试入口。

## 会话、草稿与重置隔离

离线模式启动后自动进入模拟管理员，无需真实账号密码；可在工具条切换身份。离线会话、场景状态、任务焦点和工作流草稿使用专用的浏览器存储名称，与正常运行模式分开。切换工具条状态前会要求确认，因为未保存的编辑输入和本次模拟修改会被丢弃。重置只清除离线修改和缓存，并保留当前选择的角色、数据状态、任务状态、训练阶段和延迟配置；不会清除在线模式的数据。

## 支持与不支持的操作

支持的离线响应覆盖用于页面检查的认证、数据中心读取、治理目录/模板/运行/结果、任务详情与日志，以及算子和训练工作台的选定读取流程。列表请求保留页面所需的筛选、搜索和分页形状。

上传操作不受支持。工具条中的“载入示例文件”会打开预置文件的详情，不读取或解析任意用户文件。治理提交、重运行和取消只返回固定的合成任务状态；它们不会执行真实计算。

数据文件、集合、视图、治理模板和其他资源的真实创建、修改、删除、发布与持久化不属于离线模式；治理模板仅提供已知状态交互。工作流编辑器的会话草稿保存是支持的离线例外。未覆盖的请求会失败关闭并显示“离线模式尚未实现此请求”，不会转发到真实 API。

## 页面覆盖与验收状态

| 页面范围 | 可检查内容 |
| --- | --- |
| 数据中心 | 集合、文件、质量、治理运行、模板和结果读取 |
| 算子中心 | 目录、筛选和选定详情 |
| 训练工作台 | 选定模型、训练阶段和结果展示 |
| 工作流编辑器 | 会话草稿保存、数据绑定和结果查看 |
| 快速试用 | 示例数据和预览状态 |
| 管网数据 | 合成拓扑与相关读取状态 |
| 用户与角色 | 模拟身份和权限显示 |
| 回收站 | 选定空态和任务状态展示 |

已验证数据中心治理配置到结果、训练配置到结果、工作流编辑保存与刷新恢复，以及快速试用固定结果、访客限制、空数据和错误状态。训练结果页已检查1440、1024、768、390px屏宽；这些检查不代表真实后端联调或算法效果验证。

首版固定主工作流使用301；快速试用或新增草稿使用独立辅助槽302，不覆盖主工作流。再次创建辅助草稿会提示先重置离线样例。配置页和结果页用于视觉调试，不承诺对任意参数执行真实数据校验。

## 明确排除项

离线模式不连接真实 API，不包含生产数据、真实业务结果、模型权重或训练产物，也不会启动训练、GPU 任务、数据库迁移或部署。所有结果和时间序列均为合成展示数据；不要据此作出质量、漏损或预测判断。

## 排障

若页面显示“离线模式尚未实现此请求”，打开工具条中的诊断列表，记录请求方法和路径，并为对应功能补充受控 handler 与合成 fixture。不要通过关闭离线后端或修改真实 API 地址绕过问题。若启动失败，确认使用的是 `npm run start:offline`、页面地址为 `http://localhost:4201`，且浏览器没有把请求重定向到其他主机。
