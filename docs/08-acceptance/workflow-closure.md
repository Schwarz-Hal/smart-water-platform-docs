# 系统全流程闭环验收与验证指南

本指南用于验证智慧水务算法平台各项核心功能是否达到可用标准，确保时序数据接入、算子拓扑编排、异步分布式执行与结果溯源形成完整业务闭环。

---

## 1. 验证步骤

1. **时序数据接入与治理**：上传标准管网监测 CSV 数据集，完成时间列与指标映射，确认数据通道可用及自动质量评估报告正常生成；
2. **算子与参数配置**：在算子中心查阅输入输出端口契约，验证管理员在线调整默认参数及即时 Schema 校验生效；
3. **工作流编排与图校验**：在画布中完成节点连接与参数绑定，执行图校验确保拓扑无孤立节点或类型冲突，发布为不可变流程版本；
4. **异步任务调度与执行**：触发工作流运行，观察 Celery 任务状态流转（PENDING → RUNNING → SUCCESS），检查节点实时标准输出与运行日志；
5. **结果可视化与指标呈现**：进入运行详情页，检视时序预测折线图、DMA 漏损候选风险表与聚合统计报告；
6. **历史追溯与复现性核验**：跨会话重新加载历史运行实例，验证其关联的数据快照、算子版本与执行参数保持精确一致。

---

## 2. 验收核验点矩阵

| 功能模块 | 验证项 | 预期标准 |
| :--- | :--- | :--- |
| **数据资产** | CSV 导入与通道划分 | 成功解析时序时间戳与指标字段，支持多通道预览与不可变版本化。 |
| **算子中心** | 契约展示与默认参数调整 | 参数规则卡片清晰呈现类型与取值约束，管理员调整后自动通过 Schema 强校验。 |
| **工作流编排** | 可视化连线与发布 | 画布响应流畅，图校验即时拦截类型不匹配，发布后拓扑不可篡改。 |
| **执行引擎** | 分布式异步调度与日志 | 任务状态与进度实时推送，支持失败重试机制与全局 `trace_id` 关联。 |
| **结果追溯** | 报告导出与血缘溯源 | 结构化呈现指标与图表，准确追溯至上游数据版本与算子快照。 |
