# 系统全流程闭环验收与验证指南

本指南将全流程验收拆成可执行步骤。每个通过结论都必须补充结构化证据，不以文档存在或样例描述代替运行记录。

## 1. 验收步骤

- [ ] 接入测试数据并完成字段映射，记录资产版本和质量报告。
- [ ] 配置算子、参数和连接，记录参数快照及图校验结果。
- [ ] 发布不可变工作流版本，记录发布人、版本和审计信息。
- [ ] 运行工作流并记录任务状态、节点日志和 trace_id。
- [ ] 查看结果报告并记录 Artifact、导出文件和指标来源。
- [ ] 重新加载历史运行，核对数据、算子、参数和工作流版本。

## 2. 预期结果

每一步均能由记录的版本、任务或报告标识复核；失败、跳过或未执行步骤不得标记为通过。
