# 查阅平台文档

## 用途

查找操作说明、算法参考和开发资料，帮助完成平台中的各项工作。

## 前置条件与角色

在侧栏点击【开发文档】打开文档网站。在线文档可直接阅读。

## 操作步骤

1. 从网站导航进入所需栏目。日常操作优先查阅用户操作手册，算法使用要求可在算法参考中查找。
2. 使用页面目录跳转到需要的步骤；阅读操作说明时，对照平台中的按钮名称执行。
3. 需要查找具体问题时，打开文档搜索，输入功能名称或关键词。
4. 在搜索结果中选择相应章节。内容较多时，缩小关键词范围，再检查相关步骤和常见问题。
5. 在平台算法详情提供文档入口时，也可从该入口查看对应说明。
6. 需要离线阅读或交付文件时，使用维护人员提供的 Word、PDF 或离线文档包。

## 结果与失败处理

页面加载失败时，检查网络连接后重试。搜索暂未显示结果时，等待索引加载，或从栏目目录查找。

平台中的可用操作受账户权限和所选资源状态影响。遇到按钮名称或步骤与页面不符时，可将所在页面和提示信息反馈给管理员。
