# 文档中心、版本快照与离线文档

平台内置了现代化的技术文档中心，为各级用户提供全天候的在线查阅、全文搜索与离线交付手册导出能力。

---

## 1. 在线阅读与全文检索

- **科技青蓝工业风界面**：提供清晰的三级分类导航、代码高亮、KaTeX 数学公式渲染与 Mermaid 交互式流程图；
- **毫秒级 Pagefind 全文检索**：按键盘快捷键 `Ctrl + K` 或点击顶部搜索框，支持对 90+ 篇文档、算子参数与 API 契约进行即时关键词联想与全文索引。

---

## 2. 不可变版本快照与离线包导出

- **版本快照切换**：在文档中心顶部可自由切换查看当前正式版本与历史交付版本快照（如 `snapshot-202608`）；
- **离线手册导出**：支持一键将整站文档或特定章节导出为单文件 PDF 或静态 HTML 离线压缩包，满足涉密水务内网离线部署环境下的查阅需求。
