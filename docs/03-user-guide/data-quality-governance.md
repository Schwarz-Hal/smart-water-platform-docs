# 质量报告、治理方案与派生版本

## 用途

质量报告帮助用户判断数据是否适合分析。对于数据文件，可在【数据文件】中打开【数据治理工作台】，选择一个精确的不可变文件版本和已批准的治理算子，生成报告、变更集、问题掩码、溯源信息，以及需要时的治理后文件版本。

治理运行始终保留来源版本。它不会修改原始文件或历史版本；生成新版本、生成新文件与仅生成报告是三种明确的输出选择。

## 前置条件与角色

- 需要数据文件读取权限，才能查看质量信息、可用治理算子、历史运行和输出。
- 需要数据文件写入权限，才能创建治理运行或重跑终态运行。
- 来源文件版本必须已经准备完成，且不超过 200 MB。当前工作台只处理受支持的结构化文件；不支持的格式和仍在解析的版本不能提交。
- 生成新文件时，目标数据集必须处于活动状态，且当前账户对其有写入权限。未指定目标数据集时，新文件默认归入来源文件所在的数据集；来源没有归属时，新文件也保持无归属。

## 操作步骤

### 数据中心的四个入口

数据中心按使用目的组织为【数据资产】【质量概览】【治理任务】【规则与模板】。评估、清洗、修复、增强和标注共用治理任务系统，不是五套独立的数据处理链路。

- **数据资产**：管理数据集和无归属文件；查看当前版本、自动画像质量和该版本的治理状态。点击文件行的治理类别，可直接选择该类别中适用的操作。文件的历史版本不会继承新版本的处理状态，反之亦然。
- **质量概览**：查看当前版本的自动画像覆盖和评分，选择文件查看质量维度、问题和报告。自定义规则报告与自动画像分开查看；未评估不等于零分，执行成功也不代表数据完全合格。
- **治理任务**：跨文件查找治理运行，按状态和类别筛选，打开精确运行查看阶段、结果或失败原因。结果文件与来源文件都能关联到相应运行。
- **规则与模板**：复用个人配置或管理员维护的共享配置；应用到新文件时重新确认字段匹配，不会自动改变已运行任务。

### 1. 查看已有质量报告

1. 在【数据源与导入】的【可用数据资产】中打开【详情与治理】，选择要查看的资产版本。
2. 在旧数据资产详情查看当前版本、版本血缘树、指标通道和【质量报告】列表。此旧入口与数据文件的【质量概览】是不同界面。
3. 需要使用旧数据资产治理流程时，点击【创建治理工作流】；入口会带入当前资产版本，并预选 `timeseries_governance_basic`，随后按工作流页面的实际配置继续。

### 2. 在数据文件中创建治理运行

1. 打开【数据中心】→【数据资产】，进入包含目标文件的数据集或【无归属】目录。
2. 在文件菜单中选择【数据治理】。工作台会默认选择当前版本；如需复现历史内容，在【选择操作】中改选指定历史版本。
3. 查看可用算子。工作台仅列出与来源文件类型兼容、已安装且可运行的算子。可使用单一操作，或在高级配方中按执行顺序添加、移除和调整多个步骤。
4. 按下表理解算子类型和当前可用范围。报告型步骤可以放在转换步骤之前、之间或之后；若选择【仅生成报告】，配方只能使用报告型步骤。生成版本或新文件时，配方必须至少包含一个转换或标签步骤。

| 类别 | 首批内置操作 | 结果类型与当前范围 |
| --- | --- | --- |
| 质量与业务检查 | 质量、结构、时间和水务检查 | 报告型：生成质量/问题/溯源结果，不物化新数据 |
| 规范化与清洗 | 标记规范化、排序、去重、缺失值修复、异常值修复 | 转换或标签：可生成数据、变更集和问题掩码 |
| 表格与时序转换 | 类型转换、列重命名、语义重采样 | 转换：兼容的表格和时序操作也可作为工作流节点 |
| 文件专项处理 | 重塑、拓扑处理 | 转换：当前只在数据文件工作台提供，不代表已经可用于通用工作流 |

1. 在【配置规则】中填写每个步骤显示的参数。对一般表格执行缺失值或异常值修复时，明确选择要处理的列；不要把未选择的业务列视为已经修复。已完成时间画像的来源会自动带入识别出的时间列；主时间间隔只会预填到时间轴完整性检查的 `expected_interval_seconds`，语义重采样的目标间隔仍需自行选择。提交前应确认这些默认值适合本次数据。参数不符合该算子契约时不能提交；平台会在提交时再次检查，不以浏览器检查代替服务端校验。
2. 在【配置规则】中选择输出目标，并在【确认执行】核对：
   - 【仅生成报告】：保留分析结果，不创建文件或版本；
   - 【生成新版本】：为同一逻辑文件创建不可变版本。默认在完成后将它设为当前版本；
   - 【生成新文件】：可保留界面预填的中文名称、修改名称，或不填写而使用平台生成的治理后 Parquet 名称；按需要选择目标数据集。未改变默认选择时，使用来源文件的数据集归属。
3. 点击【开始治理】。页面显示整体任务和各步骤的状态。运行期间可以选择【后台继续运行】或关闭对话框；稍后从文件的治理历史重新打开即可恢复查看。

工作台采用【选择操作 → 配置规则 → 确认执行 → 运行与结果】四步。返回上一步保留已填参数；关闭未提交的配置需要确认放弃。字段选项独立于数据预览加载；预览最多显示50行，不代表实际治理只处理50行。预览失败时可在对应区域重试。

### 保存和使用模板

进入【规则与模板】→【创建模板】，选择参考文件和版本以读取字段、添加操作并配置参数后保存。普通用户保存个人模板，管理员还可以创建共享模板。此入口独立于治理工作台；模板保存精确算子版本、步骤顺序、参数和字段要求，不把参考文件作为唯一输入。

1. 在【规则与模板】中选择可见模板，或将共享模板复制为个人模板。
2. 应用时选择来源数据版本。同名同类型的字段可预填，未匹配字段必须重新选择；确认参数适合本次数据后再提交。
3. 更新模板产生新的修订。运行记录冻结提交时的实际配方与来源模板修订，不跟随后续模板更新。
4. 归档模板不会删除历史运行或治理结果。

### 运行反馈与连接恢复

- 进度条表示阶段进度，不是剩余时间预测；不能统计处理行数的步骤只显示实际阶段与耗时。
- 网络暂时中断时显示同步提示及最后同步时间，不会因此把任务判定为失败。恢复连接或重新进入页面后读取服务端状态。
- 当前会话中关注的治理任务可在关闭弹窗后继续追踪。页面刷新或从任务入口重开时按运行ID恢复结果；退出登录会清理本机当前用户的追踪状态。
- 申请取消后，当前算法可能需要执行到安全边界。以服务端显示的最终取消状态为准，不能把点击按钮等同于已停止计算。
- 失败页保留失败步骤、可读原因和重跑入口。日志加载失败不应妨碍查看任务终态；技术详情中的任务ID和错误码可用于向维护人员反馈。

### 3. 查看结果、下载输出或重跑

1. 成功完成后，在结果区查看来源、配方、任务状态、质量前后对比和各步骤摘要。来源动作始终打开本次运行冻结的精确来源版本，不会跳转为后来更新的当前版本；生成数据后，结果动作打开该次运行实际创建的结果版本，并可在血缘中查看与来源的关系。
2. 结果区仅展示报告、变更集、问题掩码和样本的有界摘要，避免一次加载完整大文件。需要完整或重放结果时，使用对应下载按钮；下载经过权限验证，页面不会显示对象存储位置或内部路径。
3. 在文件的【治理历史】中选择某次运行，可再次查看其冻结的来源版本、参数和输出。历史运行不会随当前文件版本或算子目录的更新而变化。
4. 只有完成、失败或已取消的运行可以【按原配置重跑】。重跑创建新的任务和治理运行，并保留与原运行的关联；它不会覆盖原结果。

## 结果与失败处理

### 按测点比较处理前后的时序

结果区的【处理前后时序对比】位于质量维度柱状图之前。它读取本次运行冻结的来源版本和实际结果版本，不使用当前版本，也不把前 50 行样本当作完整趋势。

1. 打开结果后自动复用时间画像或明确的时间字段类型，识别常见点位字段并选择首个点位，默认展示数值指标。无法确定时间列时，在【字段设置】中选择；自动选择不符合业务含义时也可在此纠正。
2. 多点位文件在左上方切换点位；单点位直接显示名称。大量点位可在字段设置中查找并翻页。
3. 旁边的彩色圆点和指标名可点击隐藏或显示曲线，最多同时显示 6 项；窄屏图例位于曲线上方。同指标前后保持同色，以虚线和实线区分处理前后。不同指标分图，共享时间轴并保留原始单位。
4. 自动确定完整时段，初始显示最早的一天；不足一天时显示全部。拖动下方缩略时间轴上的窗口左右浏览，窗口跨度保持不变。也可用【前一段】【后一段】按钮，或把【窗口跨度】切换为 6 小时、1 天、3 天、7 天。【回到起点】恢复首个一天窗口。
5. 缩略轴使用全时段有界抽样；窗口移动后自动补读当前时段细节。超过点数上限时显示抽样状态，可缩小跨度查看细节。前后序列保留各自时间戳，重采样结果不会按行号强制对齐。
6. 【查看窗口数据】展开阶段、指标、时间和值，时间以浏览器本地时区显示。缺失值用 `—` 表示并在曲线上断开；已存时间画像确认的缺口也保留断点。质量维度与原始表格样本在次级区域展开查看。

仅报告运行未生成结果文件时，只显示来源序列，不伪造“处理后”曲线。未确定时间字段或不支持表格时序的文件不强制绘图。图表请求失败可在本区重试，不改变治理结果。曲线用于解释处理效果，不能取代完整质量报告或业务核验。

质量报告和派生版本状态以任务与文件版本实际显示为准。治理完成后，新版本或新文件可以作为后续分析输入，父版本仍可查看；仅生成报告不会创建新版本。

| 情况 | 处理方式 |
| --- | --- |
| 来源版本正在解析、不可读或超过 200 MB | 等待解析完成，选择已准备的版本，或拆分文件后重新提交 |
| 当前文件没有可用算子 | 确认文件类型与版本状态；当前首批仅支持已批准的内置治理算子 |
| 参数或目标配置无效 | 检查步骤顺序、所选列、时间列默认值、参数范围和目标类型；仅报告目标不能包含转换/标签步骤，物化目标至少需要一个转换/标签步骤 |
| 运行显示来源或算子已变化 | 返回工作台重新读取目录和版本后提交；不要试图用旧配置绕过冻结校验 |
| 运行失败 | 打开任务和步骤摘要确认错误，修正输入后创建新运行或对终态运行执行重跑 |
| 找不到历史运行或输出 | 确认当前账户对来源文件仍有读取权限；无权访问与不存在会使用相同的不可见语义 |

内置只读来源可以用于仅生成报告，或在账户拥有任务写入权限时生成新文件；它不能被治理为新的内置来源版本。质量报告、变更集和问题掩码用于说明数据处理过程，不是业务结论，也不应替代现场核验或业务审批。当前工作台不包含跨文件拼接、持续或定时治理、手工编辑对象内容、未审核外部算子、版本合并或跨用户公开共享。
