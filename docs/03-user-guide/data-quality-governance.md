# 质量报告、治理方案与派生版本

## 用途

质量报告帮助用户判断数据是否适合分析。对于数据文件，可在【数据文件】中打开【数据治理工作台】，选择一个精确的不可变文件版本和已批准的治理算子，生成报告、变更集、问题掩码、溯源信息，以及需要时的治理后文件版本。

治理运行始终保留来源版本。它不会修改原始文件或历史版本；生成新版本、生成新文件与仅生成报告是三种明确的输出选择。

## 前置条件与角色

- 需要数据文件读取权限，才能查看质量信息、可用治理算子、历史运行和输出。
- 需要数据文件写入权限，才能创建治理运行或重跑终态运行。
- 来源文件版本必须已经准备完成，且不超过 200 MB。当前工作台只处理受支持的结构化文件；不支持的格式和仍在解析的版本不能提交。
- 生成新文件时，目标数据集必须处于活动状态，且当前账户对其有写入权限。未指定目标数据集时，新文件默认归入来源文件所在的数据集；来源没有归属时，新文件也保持无归属。

## 操作步骤

### 1. 查看已有质量报告

1. 在【数据源与导入】的【可用数据资产】中打开【详情与治理】，选择要查看的资产版本。
2. 在资产详情查看当前版本、版本血缘树、指标通道和【质量报告】列表。页面没有单独的 Quality/【质量评估】页签，也没有手动重新评估按钮。
3. 需要使用旧数据资产治理流程时，点击【创建治理工作流】；入口会带入当前资产版本，并预选 `timeseries_governance_basic`，随后按工作流页面的实际配置继续。

### 2. 在数据文件中创建治理运行

1. 打开【数据中心】→【数据文件】，进入包含目标文件的数据集或【无归属】目录。
2. 在文件菜单中选择【数据治理】。工作台会默认选择当前版本；如需复现历史内容，在【来源与操作】中改选指定历史版本。
3. 查看可用算子。工作台仅列出与来源文件类型兼容、已安装且可运行的算子。可使用单一操作，或在高级配方中按执行顺序添加、移除和调整多个步骤。
4. 按下表理解算子类型和当前可用范围。报告型步骤可以放在转换步骤之前、之间或之后；若选择【仅生成报告】，配方只能使用报告型步骤。生成版本或新文件时，配方必须至少包含一个转换或标签步骤。

| 类别 | 首批内置操作 | 结果类型与当前范围 |
| --- | --- | --- |
| 质量与业务检查 | 质量、结构、时间和水务检查 | 报告型：生成质量/问题/溯源结果，不物化新数据 |
| 规范化与清洗 | 标记规范化、排序、去重、缺失值修复、异常值修复 | 转换或标签：可生成数据、变更集和问题掩码 |
| 表格与时序转换 | 类型转换、列重命名、语义重采样 | 转换：兼容的表格和时序操作也可作为工作流节点 |
| 文件专项处理 | 重塑、拓扑处理 | 转换：当前只在数据文件工作台提供，不代表已经可用于通用工作流 |

1. 在【配置】中填写每个步骤显示的参数。对一般表格执行缺失值或异常值修复时，明确选择要处理的列；不要把未选择的业务列视为已经修复。已完成时间画像的来源会自动带入识别出的时间列；主时间间隔只会预填到时间轴完整性检查的 `expected_interval_seconds`，语义重采样的目标间隔仍需自行选择。提交前应确认这些默认值适合本次数据。参数不符合该算子契约时不能提交；平台会在提交时再次检查，不以浏览器检查代替服务端校验。
2. 在【确认与输出】中选择一种目标：
   - 【仅生成报告】：保留分析结果，不创建文件或版本；
   - 【生成新版本】：为同一逻辑文件创建不可变版本。默认在完成后将它设为当前版本；
   - 【生成新文件】：可保留界面预填的中文名称、修改名称，或不填写而使用平台生成的治理后 Parquet 名称；按需要选择目标数据集。未改变默认选择时，使用来源文件的数据集归属。
3. 点击【开始治理】。页面显示整体任务和各步骤的状态。运行期间可以选择【后台继续运行】或关闭对话框；稍后从文件的治理历史重新打开即可恢复查看。

### 3. 查看结果、下载输出或重跑

1. 成功完成后，在结果区查看来源、配方、任务状态、质量前后对比和各步骤摘要。来源动作始终打开本次运行冻结的精确来源版本，不会跳转为后来更新的当前版本；生成数据后，结果动作打开该次运行实际创建的结果版本，并可在血缘中查看与来源的关系。
2. 结果区仅展示报告、变更集、问题掩码和样本的有界摘要，避免一次加载完整大文件。需要完整或重放结果时，使用对应下载按钮；下载经过权限验证，页面不会显示对象存储位置或内部路径。
3. 在文件的【治理历史】中选择某次运行，可再次查看其冻结的来源版本、参数和输出。历史运行不会随当前文件版本或算子目录的更新而变化。
4. 只有完成、失败或已取消的运行可以【按原配置重跑】。重跑创建新的任务和治理运行，并保留与原运行的关联；它不会覆盖原结果。

## 结果与失败处理

质量报告和派生版本状态以任务与文件版本实际显示为准。治理完成后，新版本或新文件可以作为后续分析输入，父版本仍可查看；仅生成报告不会创建新版本。

| 情况 | 处理方式 |
| --- | --- |
| 来源版本正在解析、不可读或超过 200 MB | 等待解析完成，选择已准备的版本，或拆分文件后重新提交 |
| 当前文件没有可用算子 | 确认文件类型与版本状态；当前首批仅支持已批准的内置治理算子 |
| 参数或目标配置无效 | 检查步骤顺序、所选列、时间列默认值、参数范围和目标类型；仅报告目标不能包含转换/标签步骤，物化目标至少需要一个转换/标签步骤 |
| 运行显示来源或算子已变化 | 返回工作台重新读取目录和版本后提交；不要试图用旧配置绕过冻结校验 |
| 运行失败 | 打开任务和步骤摘要确认错误，修正输入后创建新运行或对终态运行执行重跑 |
| 找不到历史运行或输出 | 确认当前账户对来源文件仍有读取权限；无权访问与不存在会使用相同的不可见语义 |

内置只读来源可以用于仅生成报告，或在账户拥有任务写入权限时生成新文件；它不能被治理为新的内置来源版本。质量报告、变更集和问题掩码用于说明数据处理过程，不是业务结论，也不应替代现场核验或业务审批。当前工作台不包含跨文件拼接、持续或定时治理、手工编辑对象内容、未审核外部算子、版本合并或跨用户公开共享。
