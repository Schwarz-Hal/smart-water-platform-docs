# 数据质量检查与治理

## 用途

检查数据中的缺失、异常和时间问题，按需要生成质量报告或处理后的数据，供后续分析使用。

## 前置条件与角色

来源文件应已完成解析。从【数据中心】打开数据集或【无归属文件】，在文件行点击【检查与治理】。Excel 需先选好工作表并按提示确认表头；如提示确认时间列，按资料实际含义选择。

## 操作步骤

1. 打开检查窗口，核对文件。Excel 先选择工作表并确认表头；如提示确认时间列，按资料实际含义选择，再点击【开始检查】。打开窗口本身不会提交新任务。
2. 若已有与当前资料及检查范围匹配的报告，直接查看；若已有匹配任务正在执行，继续查看进度，不重复提交。检查只生成报告，不修改原文件；如只需了解质量，读完即可关闭。INP 文件在此入口仅进行结构检查。
3. 需要处理且报告提供【查看治理方案】时，点击后在同一窗口选择或调整处理步骤。只有质量报告已发现完全重复记录时，才默认提出完全重复记录清理与质量复查；其他情况由用户明确选择操作。不默认补零、插值、替换异常值或重采样。
4. 按顺序查看治理步骤。参数默认收起；点击步骤卡片展开修改，再次点击收起。显示【待完善参数】的步骤需补全后才能继续。需要增减操作时点击【调整操作】，在选择页修改后返回参数配置。
5. 点击【下一步：保存结果】。保存页只设置保存方式、文件名称和目标数据集，不重复展示步骤与参数。默认另存为新文件，原文件不变；只有满足下述条件时，才可选择更新当前文件。核对后点击【确认并治理】；仅包含检查的方案只生成报告。
6. 完成后查看质量报告、处理摘要和处理前后曲线，按需要下载结果或查看处理后的数据。结果区的保存提示说明数据实际保存的位置。

### 保存方式与更新限制

从检查报告进入治理时，更新当前文件要求：来源是有写权限的非内置 CSV 或 Parquet 文件，使用的版本仍是文件当前版本，已有成功且匹配该版本的检查报告，并且所选处理步骤支持此保存方式。更新会生成并设定新的当前版本，原始版本仍保留。Excel 工作表的处理结果须另存，不能更新原工作簿；INP 在此入口仅支持结构检查。

如果检查后文件版本或工作表选择发生变化，服务端会拒绝失效报告，需重新检查。执行期间若原文件的当前版本已变化，结果可能保存为新版本但不切换当前版本；以结果区的保存提示和运行警告为准。

## 回看检查与复用配置

重新从同一文件的【检查与治理】进入时，窗口会尝试恢复匹配当前资料及工作表选择的运行中任务或成功检查报告。点击同一窗口中的【历史记录】，可翻页查看检查报告和治理任务；点击某条记录的【查看】只打开当时保存的来源、步骤、设置与结果，不重新执行。

需要重复执行历史任务时，点击【按原配置重跑】，核对提示后再点【确认重跑】，平台会按该记录的来源、步骤和保存设置创建新任务。需要改用当前数据时，选择【使用当前数据配置】，重新核对来源、字段、步骤及保存方式。相关操作按权限开放。

## 结果与失败处理

关闭运行窗口后，任务可在后台继续。重新进入同一文件的【检查与治理】可尝试接续仍在运行的任务；失败时按提示检查文件、字段和参数。原始文件保留，处理结果按所选输出方式保存。
