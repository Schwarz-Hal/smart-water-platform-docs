# 场景实例与数据资源运行

## 用途和范围

场景实例把已启用的声明式场景模板、数据选择和参数组合成个人可复用配置，再提交现有工作流运行。实例会冻结模板声明、数据选择和参数，结果通过现有工作流和标准结果能力查看。

本功能是数据资源到既有工作流的最小桥接，不是完整新漏损算法，也不提供自动定时、人工确认报告或任意拓扑水力计算。当前首批运行报告是自动生成的运行报告；人工确认版和定时首版属于后续方向。

## 前置条件与角色

需要登录，并具有 `workflow:read` 查看模板/实例、`workflow:edit` 创建实例、`workflow:run` 运行实例的权限，同时具备所选数据文件的读取权限。普通用户只能看到自己的实例；管理员按现有策略查看管理范围内实例。

模板必须处于已启用状态，并引用平台已安装的精确 workflow、算法或算子版本。被停用、归档、缺少依赖或标记 `runtime_required` 的模板不能用于新运行。

## 创建实例

1. 打开场景模板列表，选择一个已启用模板。
2. 按模板的 `required_bindings` 选择数据资源、资源版本、点位/指标/通道和时间范围；跨集合来源仍逐项检查权限。
3. 按模板参数 Schema 填写参数。表单优先展示声明的字段和类型，不要求普通用户手写 JSON。
4. 提交创建，等待服务器完成参数、权限和数据适用性检查。
5. 创建成功后，实例详情显示模板版本、数据选择、参数、快照和最近一次运行。

创建时会检查模板声明的 `required_bindings`、资源 `kind`/`calculation` 适用性和时序窗口是否非空。检查失败时实例不能创建或运行，并返回具体错误；当前不是完整的阶段、覆盖率或条件分支规则引擎。缺少拓扑只影响明确依赖拓扑的流程，必需输入不能被静默跳过，也不能据此宣称完成完整业务分析。

## 运行实例

1. 在实例详情确认模板和数据快照，点击运行。
2. 为本次请求提供幂等请求标识；相同实例和标识的重试会返回同一运行结果。
3. 页面返回 workflow、run 和 task 标识后，从任务中心或工作流运行详情查看状态。
4. 运行完成后查看标准结果和自动运行报告。当前 HTML 报告可通过 `GET /api/v1/scene-instances/{instance_id}/runs/{run_id}/report` 获取；前端使用认证后的 Blob 下载。报告包含运行状态、冻结输入/参数和输出清单，不应理解为完整漏损业务报告或人工确认版。

运行调用会再次检查模板仍已启用且数据权限仍有效。运行中的追加、模板更新或后续停用不改写已经冻结的运行。不同幂等标识代表新的运行，需注意资源和任务成本。

## 查看历史和恢复

实例列表和详情显示最近运行；工作流运行接口保留运行状态、节点、结果和报告。刷新、暂时断网或关闭页面后，可用实例和任务标识重新打开状态。任务失败或取消时，查看终态错误后再重试，不把 HTTP 接收成功当作工作流执行成功。

已提交运行使用当时的模板、数据、算法/算子和参数快照。模板停用只阻止新的运行，不删除历史结果；归档前会检查引用，不能物理删除仍被历史使用的精确版本。

## 常见限制

| 情况 | 结果 |
| --- | --- |
| 模板不存在、未启用或版本不精确 | 创建/运行被拒绝，选择仍保留供修正 |
| 数据资源不可见或权限不足 | 按资源不可见/无权限处理，不通过映射绕过 |
| 单位或时区未知 | 可保留资源预览，但单位敏感或跨源对齐计算不适用 |
| 缺少拓扑 | 不依赖拓扑的流程可继续；必需拓扑的流程被门禁阻止 |
| workflow 必需输入缺失 | 阻止对应运行，不静默跳过节点 |
| 模板含代码运行需求 | 显示 `runtime_required`，本批不能安装或运行 |
| 报告下载失败 | 保留 run 标识并重试认证后的 HTML/Blob 下载；不自动补造业务结论 |

## 当前边界

场景实例当前复用既有 workflow run、任务恢复和标准结果接口。它不新增第二套任务引擎，不替代已有漏损工作台，不自动启用定时器，也不把拓扑连接推断成实时水力方向。若需要完整漏损闭环、定时执行或人工确认版，应等待相应功能完成并单独验收。
