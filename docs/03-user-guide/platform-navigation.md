# 平台导航与模块入口

## 用途

左侧导航用于进入平台各功能页面。分析任务在项目工作台中完成，资料整理、流程管理及扩展管理也可分别进入对应页面处理。

## 常用入口

| 入口 | 主要用途 |
| --- | --- |
| 开启新任务 | 选择业务和分析流程，准备资料并创建项目 |
| 数据中心 | 查找、上传和整理文件与数据集 |
| 算法中心 | 浏览算法与算子，查看说明、参数及可用操作 |
| 流程中心 | 查找已有项目，打开草稿、查看版本和分析记录 |
| 资源广场 | 查找扩展，了解其提供的节点、模板和结果视图 |
| 快速试用 | 使用现成入口体验单项分析或数据处理 |
| 开发文档 | 阅读操作说明和开发参考 |

## 操作步骤

1. 点击【开启新任务】，选择业务，或输入目标查找适用方案。选择可用流程后继续准备数据。
2. 处理已有工作时，点击侧栏【最近项目】，或进入【流程中心】搜索项目并打开。
3. 在项目内，按页面的主操作推进数据浏览、流程编排和分析结果。普通流程可在【编排】与【分析工作台】之间切换。
4. 需要集中整理资料时，进入【数据中心】。完成整理后，返回项目继续选择或使用这些资料。
5. 从侧栏底部【账户与设置】登录、退出或处理账户操作。管理员可从旁边的管理菜单进入运行管理、任务管理、用户管理和回收站。

## 常见问题

导航可以收起，点击左上角菜单按钮重新展开。某项入口或操作没有显示时，请确认登录状态及账户权限。业务目录中尚未提供方案的项目会显示准备状态，可先选择当前可用的方案。

离开项目之前，检查保存状态；页面提示仍在保存或有未保存修改时，先返回当前项目完成保存。
