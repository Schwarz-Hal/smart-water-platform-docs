# 平台导航与模块入口

## 用途

本文帮助平台用户从主导航找到工作台、数据、场景、算子、扩展与运行相关页面，并解释相似入口之间的关系。菜单只提供导航；页面或操作能否使用，仍由账户状态、相应权限和资源访问范围决定。

## 前置条件与角色

已登录用户可看到自己有权访问的导航入口。管理员可按职责访问用户管理或资源回收站；其他用户不会因为看见某个页面标题而自动获得管理权限。访客可以使用公开的快速试用页面，其他要求登录的入口需要先登录。

## 主导航

在桌面端使用左侧“工作空间”菜单；窄屏时先点页面左上角的菜单按钮展开导航。主菜单会按权限隐藏不适用的入口，常见模块如下：

| 入口 | 用途 | 页面路径 |
| --- | --- | --- |
| 快速试用 | 直接进入单算法试用、管网漏损闭环及数据治理入口 | `/quick-trial` |
| 工作台 | 查看平台摘要、最近任务，并继续常用工作 | `/dashboard` |
| 数据集管理 | 管理文件与数据集、查看质量和治理内容，并访问拓扑与时序资源 | `/data-collections` 或 `/data-resources` |
| 场景中心 | 浏览场景、打开 DAG 节点图、管理草稿和已发布版本 | `/workflows` |
| 算子中心 | 查找可用算子及其信息 | `/operators` |
| 扩展中心 | 浏览和管理可用扩展 | `/extensions` |
| 运行中心 | 查看场景运行记录或后台任务 | `/workflow-runs` 或 `/tasks` |

当前账户能看到的数据集管理默认入口取决于可用的数据读取权限。没有某项权限时，入口可能隐藏；访问受限 URL 也不会绕过页面的权限检查。遇到无法访问的页面，请联系平台管理员确认账户角色及目标资源授权。

## 数据集管理中的页面

进入“数据集管理”后，使用页面内的模块导航切换以下内容：

1. **文件与数据集**：查看数据资产和文件相关内容。
2. **拓扑与时序**：查看已有拓扑、点位时序及映射资源。读取时应按页面提供的版本选择器指定版本。
3. **质量概览**：查看质量报告入口。
4. **治理任务**：查看治理任务相关内容。
5. **规则与模板**：查看规则和模板。

这几项是已有页面和数据中心页签的导航组织方式，并非新的资源类型或独立服务。执行创建、发布或治理操作前，请按页面提示检查所需权限、来源和版本。

## 场景中心与历史入口

场景中心使用节点图（DAG）编辑既有工作流。可以在场景列表中打开节点图，并依据权限新建或编辑草稿、发布版本及运行场景。列表中的“我的草稿”“已发布场景”“全部可见”和“回收站”是场景列表范围，不是不同的执行引擎。

页面右上角的“历史入口”保留两个已有页面：

- **历史场景库**：打开 `/scenes`。
- **历史场景配置**：打开 `/scene-instances`。

它们保留原有地址与数据绑定；主导航标签调整不会迁移或删除这些历史页面。编辑器中的“封装为子流程节点”使用已有的已发布工作流版本注册复合算子，作为后续可复用的节点；它不会改写当前场景图，也不代表新增了子流程执行引擎。

## 运行中心：场景运行与后台任务

运行中心按权限提供两个不同入口：

- **场景运行**打开 `/workflow-runs`，用于查看工作流运行记录及对应详情。
- **后台任务**打开 `/tasks`，用于查看后台任务及任务详情。

两者保留独立页面、权限和状态来源。任务详情中的重运行等操作可能转到对应的场景运行记录；运行中心只是把入口放在一起，不会把两类记录合并成一种状态。请根据记录类型进入对应列表或详情。

## 扩展中心与 API 说明

扩展中心内可通过区域导航访问“扩展管理”和“API 与集成”。后者是现有接口目录、调用示例和集成方案的设计预览，不代表已提供真实 API Key 签发或认证能力；页面中的示例地址和凭证均为占位内容，不可作为真实服务凭证使用。它与扩展管理页面并列导航，不会改变扩展运行时能力。

用户管理与资源回收站不属于工作空间主模块，它们位于“管理与设置”区域，并按各自权限显示。若账户没有相应管理权限，这些入口可能不可见。

## 访客与快速试用

快速试用固定保留在左侧主导航，登录用户与访客均可直接进入 `/quick-trial`；工作台中的快捷入口也继续保留。其他要求登录的路由会按页面策略显示登录入口或要求先登录。访客状态下能看见的入口不代表可以访问受保护数据或提交需要登录的操作。

## 结果与失败处理

选择模块后，页面标题和区域导航会标明当前位置。若链接失效、页面提示权限不足，或列表没有目标记录：先确认是否已登录、当前账户权限和所选资源范围；再从对应主入口重新进入。不要通过修改 URL 尝试绕过权限。需要访问管理入口时，请联系平台管理员。
