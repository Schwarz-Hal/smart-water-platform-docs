# 平台导航与模块入口

## 用途

本文帮助平台用户从左侧导航进入新任务、数据、算法、流程、资源和开发页面，并说明项目视图、管理入口及访问边界。菜单只提供导航；页面或操作能否使用，仍由账户状态、既有权限和资源访问范围决定。

## 前置条件与角色

已登录用户可看到自己有权访问的导航入口。管理员可按职责访问用户管理或资源回收站；其他用户不会因为看见某个页面标题而自动获得管理权限。访客可以使用公开的快速试用页面，其他要求登录的入口需要先登录。

## 左侧导航

桌面端侧栏将入口分为“我的空间”“发现”和“开发者”，顶部【开启新任务】进入任务首页，底部为账户与管理菜单。入口会按既有角色和权限显示；调整导航不增加权限或 API。

| 区域 | 入口 | 页面路径与用途 |
| --- | --- | --- |
| 主操作 | 开启新任务 | `/workbench`：主区嵌入目标、数据选择／上传与方案确认；可切换任务目录，不会进入页面就自动弹窗。 |
| 我的空间 | 数据中心 | `/files`：默认打开【我的文件】；页面内可切换数据集、质量概览、治理记录、治理模板和拓扑与时序。 |
| 我的空间 | 算法中心 | `/operators`：查看算法与算子目录。目录可见不表示其中每项能力均可执行。 |
| 我的空间 | 流程中心 | `/workflows`：以卡片或列表浏览流程，选中后查看详情、版本和可执行操作。 |
| 发现 | 资源广场 | `/extensions`：浏览扩展目录和可访问的扩展详情；安装等生命周期操作仍按现有权限控制。 |
| 发现 | 快速试用 | `/quick-trial`：进入现有快速试用入口；受保护的操作仍需登录和相应权限。 |
| 开发者 | API 与集成 | `/developer-center`：查看接口目录、集成参考及凭证设计预览。示例 Key 不能调用接口，也不是实际签发能力。 |
| 侧栏链接 | 开发文档 | 打开平台开发文档站点。 |
| 最近项目 | 项目链接 | 侧栏展开且有最近项目记录时显示；点击可回到对应项目。它不是后台运行任务列表。 |
| 底部菜单 | 管理与账户 | 管理菜单按权限提供平台概览、运行记录、任务管理、用户管理和资源回收站；账户菜单提供登录及账户操作。 |

算法详情地址使用 `operator`、`version` 与 `tab` 参数定位算法、精确版本和详情页签；刷新后可回到该上下文，但仍需有权访问相应内容。数据中心的文件预览为只读；表格准备入口只对支持的表格格式提供，其他格式不显示该操作。

当前蓝白客户端的导航和任务首页是新界面的默认参考；青色工业风说明保留为旧设计迁移资料，不作为新页面的默认视觉规范。任务首页的目标匹配不调用 LLM。任务目录的十二项是业务方向，漏损入口在同一区域提供“流量异常初筛”“流量与压力对照”和可用的“多源协同漏损检测”流程；其他条目显示待接入。选中流程后在下方准备数据，更多管网方案可在高级配置中选择。页面入口仍沿用现有后端功能和权限。

## 数据中心页面

数据中心默认进入 `/files` 的【我的文件】。页面内导航还包括【数据集】【质量概览】【治理记录】【治理模板】和【拓扑与时序】；数据集的质量与治理相关内容继续留在现有数据中心页面，不是侧栏新增的业务任务。文件、数据集与时序资源仍按各自现有权限和精确版本规则读取或修改。

## 流程中心与项目工作区

流程中心 `/workflows` 提供卡片／列表切换、范围筛选与搜索；选中流程后在详情区查看状态、版本、运行次数和可用操作。打开流程会进入其项目工作区。

项目不再提供独立的【任务】子页；左侧【开启新任务】中的业务目录继续保留。管网项目按【数据浏览】→【流程编排】→【分析工作台】推进，顶栏显示阶段进度；普通 DAG 项目保留【编排】和【分析工作台】两个入口。原【结果】与【可视化】链接兼容到【分析工作台】。选择业务与流程后，在同一准备区选择、上传或载入演示资料，再进入绑定数据的项目。确认执行并收到运行编号后自动进入分析工作台，持续显示真实运行状态和已就绪结果；通过【调整流程】【调整数据】返回编辑，仍可回到同次分析。历史结果始终对应该次运行保存的流程和输入。

页面右上角的“历史入口”保留两个已有页面：

- **历史场景库**：打开 `/scenes`。
- **历史场景配置**：打开 `/scene-instances`。

它们保留原有地址与数据绑定；主导航标签调整不会迁移或删除这些历史页面。编辑器中的“封装为子流程节点”使用已有的已发布工作流版本注册复合算子，作为后续可复用的节点；它不会改写当前场景图，也不代表新增了子流程执行引擎。

## 管理菜单中的运行记录与任务管理

侧栏底部的【管理与设置】菜单按权限分别提供两个入口：

- **场景运行**打开 `/workflow-runs`，用于查看工作流运行记录及对应详情。
- **后台任务**打开 `/tasks`，用于查看后台任务及任务详情。

【运行记录】和【任务管理】进入不同页面，保留各自的权限与状态来源。任务详情中的重运行等操作可能转到对应的场景运行记录；菜单没有新增一个合并两类记录的中心页面。请根据记录类型进入对应列表或详情。

项目工作区的【分析工作台】采用面向业务的结果展示，保留图表、指标、报告／表格和可用制品下载；不在该展示中展开原始 JSON、技术来源、运行依据或节点日志。失败提示使用简要原因，并可引导检查数据和配置后重试。需要技术排查时，管理员可由【运行管理】打开 `/workflow-runs` 中的运行记录详情；管理员角色访问 `/workflow-runs/:runId` 时显示诊断信息，非管理员访问相同地址仍显示业务结果视图。

这是前端展示层的分工，不代表服务端响应不再包含这些信息，也不表示新增了后端角色授权或字段隔离。既有数据、权限、制品及追溯记录机制不因展示变化而删除或改变；本说明仅覆盖共享结果展示、项目运行展示和扩展结果相关界面，不表示平台所有旧页面均已调整。

## 资源广场与开发者入口

资源广场 `/extensions` 是扩展目录；算法中心 `/operators` 是算法与算子目录，两者用途不同。扩展详情中只有在账户有创建流程权限、扩展对当前账户启用且内容提供 starter 精确引用时，才显示“使用此模板”并带该模板标识和版本进入现有流程创建页。未启用、无权限或旧扩展内容没有 starter 时会显示原因；页面不会自行生成模板标识。扩展的详情、导入、安装和启停按既有生命周期及权限显示。

API 与集成页包含 API Key 设计预览、接口目录和集成方案。Key 页的创建动作只生成本地演示凭证，不能用于调用平台 API；不要把演示条目理解为已开通真实 API Key 签发或认证。侧栏【开发文档】链接到已有文档站点。

用户管理、运行记录、任务管理、平台概览与资源回收站位于侧栏底部的管理菜单，并按既有权限显示；它们不是“最近项目”的一部分。

## 访客与快速试用

快速试用位于左侧【发现】分组，登录用户与访客均可直接进入 `/quick-trial`；任务首页中的快速试用入口也继续保留。其他要求登录的路由会按页面策略显示登录入口或要求先登录。访客状态下能看见的入口不代表可以访问受保护数据或提交需要登录的操作。

## 结果与失败处理

选择模块后，页面标题和区域导航会标明当前位置。若链接失效、页面提示权限不足，或列表没有目标记录：先确认是否已登录、当前账户权限和所选资源范围；再从对应主入口重新进入。不要通过修改 URL 尝试绕过权限。需要访问管理入口时，请联系平台管理员。
