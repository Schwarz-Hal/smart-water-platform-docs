# 后台任务管理

## 用途

查看上传解析、数据处理、训练等后台任务的状态和执行进度，处理需要关注的任务。

## 前置条件与角色

具有管理权限的用户从侧栏底部【管理与设置】进入【任务管理】。普通分析工作可直接在项目分析工作台查看结果。

## 操作步骤

1. 打开任务列表，按任务类型或状态筛选，点击【查询】。
2. 在列表中查看任务名称、状态、阶段和更新时间，点击目标任务打开详情。
3. 需要查看对应业务内容时，使用任务提供的关联入口返回数据、训练或分析页面。
4. 任务仍在执行时，可按权限申请取消；提交后继续查看最终状态。
5. 失败或已结束的任务如提供重运行入口，先核对原配置，再确认重运行。
6. 需要整理记录时，使用页面允许的回收操作，并核对确认窗口中的对象。

## 结果与失败处理

刷新列表可重新读取状态。网络中断后，重新打开任务确认实际进度，避免连续提交相同操作。

失败原因可在任务详情中查看；需要排查环境或日志时，由维护人员处理。重运行会产生新的执行记录，原有记录仍可追溯。
