# 训练与模型工作台

## 用途与版本范围

【训练与模型】是算子中心下的专用子页，围绕一个精确算子版本提供【模型库】和【训练记录】。训练字段、常用及高级参数、切分方式和模型包要求来自该版本声明；没有通用训练声明的版本不能因此被视为已支持训练。

本轮 C1 使用算法 `water_adaptive_anomaly@0.4.0` 和推理算子 `water_adaptive_anomaly@1.3.0`。旧 C1 版本保留，不自动替换已有工作流。C1 仍然仅处理单测点流量和压力时序，不是图模型；SWNet 的拓扑节点数量不代表模型会联合分析全网，也不代表水力仿真。

截至 2026-09-08，服务器试用分支已部署，但新功能尚未合入主线。使用合成验收数据完成了独立 C1 GPU 训练 3 轮，运行中收到实际批次、处理量和逐轮 history；使用已有模型与显式 `fit_on_run` 的两条工作流均成功，四个输出端口均有产物。运行内快照已记录训练引用、模型文件引用、模型摘要和训练输入摘要；完整模型 ZIP 下载摘要校验、导入及新导入模型归档均通过。这些验证不代表业务检测效果或生产规模性能通过。用户登录后，模型详情、训练损失曲线、按 `run_id` 刷新恢复、复制配置及确认页均已通过浏览器验证，此次浏览器检查未新建训练。API Key 仍是独立的交互原型，不提供本工作台的新鉴权方式。

训练及模型创建时间按浏览器本地时区显示；工作流文件输入卡片按绑定的精确版本读取真实前 50 行预览，暂无数据时不生成示意曲线。

## 前置条件与角色

- 查看工作台需要算子读取权限；模型列表、详情和制品下载需要 `model:read`。
- 创建训练和查看训练记录需要 `algorithm:train`，读取训练文件还需要 `data_file:read` 及相应资源访问权限。选择已准备的精确文件版本。
- 导入与归档需要 `model:upload`；归档还检查模型所有者或管理员身份。普通用户可查看自己的模型与公共模型，不因知道模型 ID 就能下载他人私有制品。
- 设置新节点默认模型由具有发布权限的管理员操作，模型必须公开、可用并与算子绑定的算法版本一致。
- 【用于工作流】需要工作流编辑权限；自动创建数据视图时还需要对应文件与数据视图权限。后续发布、运行仍需各自权限。

## 四步训练向导

### 1. 选择数据

从算子中心进入目标版本的【训练与模型】，点击【新建训练】。填写便于识别的训练名称，选择文件和精确版本；普通表格映射声明的输入字段，SWNet 选择一个符合所需指标的测点。

C1 输入为时间、流量 `m3/h`、压力 `MPa`。普通表格应先整理成单点数据，不能混合多个测点；SWNet 点位必须真实具有 `flow` 和 `pressure`。平台不把拓扑代理值变成实测数据，也不自动换算单位。缺失、不规则或重复观测需要先显式治理，保留派生版本与来源。

### 2. 配置训练

按页面常用参数配置输入窗口、采样间隔、轮数、批大小、学习率和校准分位数；在高级参数中查看网络配置、正常记忆、设备和切分比例等声明项。参数随算法版本变化，不套用其他算法的默认值。

C1 默认按时间划分训练 70%、留出 15%、校准 15%，三段独立构造窗口。标准化器和正常记忆只拟合训练段，留出段用于早停，校准段用于阈值。每段都须容纳至少一个窗口；增加最大轮数不能弥补数据不足。

普通文件可选择已核验标签并确认其含义；默认无标签校准只返回损失和阈值，不伪造 F1。有标签的 Best-F1 是同一校准段的阈值选择结果，不是独立测试效果。

### 3. 确认提交

页面请求服务端预检查，显示来源版本、总行数、时间范围和各切分的起止时间及行数。检查是否有缺失、非有限数值、重复时间、间隔不符或窗口不足等问题。预检查未通过时先修改输入或参数，不把“确认”当作绕过校验。

核对完整配置后提交。预检查不执行训练，也不保证模型效果；创建训练会冻结实际输入绑定和参数，后续源文件当前版本变化不会改写本次训练输入。

### 4. 训练与结果

运行页展示排队、读取、准备、训练、验证、校准和保存等实际阶段，以及算法检查点已返回的轮数、批次、处理量与损失曲线。尚未返回的字段显示 `—`，没有首轮指标时等待真实输出；不会绘制模拟曲线或伪造剩余时间。

已耗时不是预计剩余时间，阶段百分比也不等于整份原始文件的逐行处理比例。不同算法或阶段可以报告不同处理单位；C1 批次处理量对应当前阶段的窗口样本，不代表源文件已经逐行处理一次。

状态同步失败会保留上次结果并提示重连，不因此判定训练失败。取消申请等待检查点与服务端终态；返回记录或关闭页面不等于取消。失败后查看错误码和任务日志，可【复制配置，重新训练】；新训练不会覆盖原运行。

## 训练记录与模型制品

【训练记录】按当前算法版本展示可见运行，可查看状态、名称和详情。运行成功后进入【查看模型】，核对来源、模型版本、兼容信息、训练指标、清单和制品摘要；模型生成、模型公开与设置默认是不同操作。

C1 完整包含 `weights.pt`、`scaler.npz`、`normal_memory.npz` 和 `manifest.json`。清单保存输入顺序、采样间隔、窗口、阈值及来源信息。模型详情提供经过鉴权的文件下载，不展示内部对象存储位置。

详情中的工作流引用只展示当前账户可见的已发布版本引用，不能据空列表认定全平台没有引用。管理员和普通用户的可见范围不同；列表不是跨所有权限边界的使用审计。

## 导入模型包

只有模型契约声明 `format=zip` 和 `required_files` 的版本提供完整 ZIP 导入。先选择正确算子版本，填写名称，并按页面必要文件清单提交；单个权重文件、缺少标准化器或记忆的包都不能代替完整模型包。

当前导入校验文件结构、清单类型和训练版本兼容性：压缩包最多 256 MB、最多 32 个根级条目、展开合计最多 1 GB，清单最多 1 MB，不接受目录或重复文件名。C1 0.4.0 的包契约允许声明训练版本为 0.3.0 或 0.4.0 的兼容包；导入后仍需在目标数据上核验。

导入结果默认私有。结构检查通过仅说明包符合当前结构契约，不证明权重正确、业务效果合格或推理已验证。不得把外部包附带的指标当作平台独立评测。

## 默认模型、归档与工作流使用

### 新节点默认模型

管理员先确认模型公开、可用且版本兼容，再选择【设为新节点默认】。默认关系针对精确算子版本；仅在新增节点时带入，不重写已有节点、已发布工作流或历史运行。也可【清除默认】，但已有显式绑定仍保留。

### 归档

归档将模型从通常的可选列表隐藏，勾选【显示已归档】可查询。仍作为新节点默认的模型须先更换或清除默认才能归档。归档不删除制品或改写历史快照，已有发布工作流保留原模型引用；新建配置不要继续选择已归档模型。

### 用于工作流

【用于工作流】创建带精确算子和模型绑定的工作流草稿，不会立即执行。模型兼容信息中存在普通文件版本和字段映射时，页面可为数值输入创建数据视图与连线；信息不足或来源为 SWNet 时，需要在编辑器继续完成输入绑定。核对数据、单位、采样间隔、端口和输出后，再按流程验证、发布和运行。

C1 1.3.0 推理从模型清单读取输入窗口，不再要求在节点上重复填写训练窗口。更换模型仍需确认数据长度和采样间隔适配；输入不足不能靠手动改小推理窗口绕过。

## 显式运行内预训练

仅当算子版本声明支持时，编辑器才提供【本次运行先预训练】。必须主动选择此模式并核对训练参数；未绑定模型不等于自动选择预训练。图中保存 `model_binding.mode=fit_on_run`，区别于选择既有模型。

该模式用本次节点实际输入先训练、留出与校准，再执行检测。它会产生并持久化训练记录和模型，节点运行快照记录训练 ID、模型版本/文件 ID、模型摘要与训练输入摘要，不是随任务结束丢弃的临时权重。训练失败、输入不满足要求或执行环境缺少支持时，不应将该节点当作已经完成推理。

运行内预训练增加实际训练成本；同一输入先拟合再检测的输出不构成独立测试效果。需要独立评估时应准备不参与训练和校准的数据，选择相应模型进行验证。

取消运行内预训练会同时取消所属工作流，页面会先要求确认；状态仍以服务端安全检查点和最终结果为准。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 新建训练不可用 | 确认版本声明支持训练，且账号有训练权限 |
| 预检查失败 | 按问题列表修正映射、间隔、缺失值或切分窗口 |
| 未出现曲线 | 等待真实首轮指标；检查同步状态和任务，不将空白解释为零损失 |
| 模型包不完整或不兼容 | 按精确版本声明补齐文件，不只修改扩展名或清单版本号 |
| 无法设置默认 | 核对管理员身份、发布权限、公开状态与算法版本一致性 |
| 不能归档 | 先确认并调整新节点默认关系，再归档 |
| 工作流仍缺输入 | 完成数据视图、端口和测点绑定；模型选择不替代数据绑定 |

相关背景见[管网数据集](network-datasets.md)与[质量报告和治理](data-quality-governance.md)。
