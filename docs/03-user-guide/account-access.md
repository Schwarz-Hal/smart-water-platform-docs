# 注册、登录、退出与账户管理

## 用途

通过登录页进入平台，并在侧栏底部的【账户与设置】菜单处理当前账户的退出或注销。注册账号后可以使用平台为普通用户开放的数据和工作流功能。

## 前置条件与角色

平台开放注册时，可在登录窗口创建普通账户。登录 ID 长 3–64 个字符，以英文字母开头，其余可用英文字母、数字、点、下划线或短横线。密码为 8–256 个字符，不要求特定的字母、数字或符号组合。显示名称用于界面展示，不是登录凭据。

## 操作步骤

1. 打开登录页或点击侧栏左下角的登录入口，在登录窗口选择【注册账号】。
2. 填写【登录 ID】【显示名称】和【密码】，点击【创建账号】。看到注册成功提示后，用登录 ID 和密码登录。
3. 要改名，点击侧栏左下角的账户名称，选择【修改显示名称】，输入新名称并保存。再次登录仍使用原登录 ID；原有资料、流程和对话仍属于同一账户。
4. 结束使用时，打开侧栏底部的【账户与设置】菜单，点击【退出登录】。
5. 如果要注销自己的账户，在侧栏底部的【账户与设置】菜单点击【注销账户】，按提示输入当前用户名和密码确认。确认后账户及其资源进入回收站并保留 14 天。

## 结果与失败处理

登录 ID 已存在时，请换一个 ID。若提示未开放注册，请联系管理员；短时间内尝试过多时，稍后再试。登录失败时先确认填写的是登录 ID，而非显示名称。新自助注册账户如需使用平台提供的智能体模型，应联系管理员开通；注册成功不代表已获得该权限。

受保护的系统账号不能注销，最后一个活动管理员也不能注销。注销成功后返回登录页，不能继续使用原会话。

## 个人模型设置（开发测试）

未登录时，点击侧栏左下角的【登录账户】直接打开登录窗口。登录后，从账户菜单或齿轮菜单进入【个人设置】。

在【模型服务】中填写 DeepSeek API Key，开启【使用自己的 API Key】并保存。该设置用于 L-Town 示例对话：发送的消息及必要分析摘要会交给 DeepSeek，原始文件和完整时序不会上传。关闭开关并保存后继续使用预设回复，普通使用不要求填写 Key。

Key 按当前账号保存在服务内存，最多保留 8 小时；服务重启后需要重新填写。关闭开关并保存会保留 Key，点击【清除 Key】将其移除。已保存的 Key 不回显，输入框留空时保留当前 Key。请使用 HTTPS 或本机安全转发入口配置。

Key 被拒绝、余额不足或请求过多时，对话中显示相应提示，可回到个人设置替换 Key 或关闭服务。
