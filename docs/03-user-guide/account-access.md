# 注册、登录、退出与账户管理

## 用途

通过登录页进入平台，并在侧栏底部的【账户与设置】菜单处理当前账户的退出或注销。注册账号后可以使用平台为普通用户开放的数据和工作流功能。

## 前置条件与角色

平台开放注册时，可在登录窗口创建账户；未提供注册入口时，请联系管理员。用户名至少 3 个字符并以字母开头；新建密码至少 8 个字符，无字符类别组合要求。

## 操作步骤

1. 打开登录页，点击【没有账号？注册】。
2. 填写【显示名称】、【用户名】、【密码】和【确认密码】，点击【注册】。注册成功后页面提示“注册成功，请登录”，再使用用户名和密码登录。
3. 登录后进入任务首页，根据需要选择业务或打开已有项目。
4. 结束使用时，打开侧栏底部的【账户与设置】菜单，点击【退出登录】。
5. 如果要注销自己的账户，在侧栏底部的【账户与设置】菜单点击【注销账户】，按提示输入当前用户名和密码确认。确认后账户及其资源进入回收站并保留 14 天。

## 结果与失败处理

用户名已存在、注册未开启、密码少于 8 个字符或两次密码不一致时，页面会提示失败原因，修正后重新提交。登录失败时检查用户名和密码；账号不是可用状态时联系管理员。受保护的系统账号不能注销，最后一个活动管理员也不能注销。注销成功后返回登录页，不能继续使用原会话。
