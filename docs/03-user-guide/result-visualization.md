# 阅读图表和评测结果

## 用途

分析结果会按照输出内容显示为图表、指标、报告或数据表。阅读时先确认所选分析记录、时间范围和单位，再查看数值及标记。

## 打开结果

在项目的【分析工作台】展开所需结果；快速试用完成后，也可直接查看其结果区域。有多项输出时，按标题选择需要阅读的内容。

## 操作步骤

1. 查看结果标题和统计范围。指标卡用于了解数量、比例或评分，完整信息可继续查看报告或数据明细。
2. 阅读时序曲线时，先看横轴时间、纵轴单位和图例。点击图例可切换系列显示，使用图表提供的缩放和复位工具查看局部变化。
3. 查看异常检测结果时，对照原始曲线、异常标记、分数和阈值，定位需要关注的时段。
4. 查看预测结果时，区分历史数据与预测区间。流程提供真实对照和评测结果时，再查看误差指标及对应的评测范围。
5. 查看质量与治理报告时，先阅读总体结果，再查看各项问题及处理前后的变化。表格可按页面提供的筛选和翻页功能查阅。
6. 需要进一步使用结果时，选择页面上的下载或导出操作，保存对应文件。

## 比较结果

比较不同记录前，核对数据范围、单位、预测长度或评测时间是否一致。MSE、MAE、RMSE用于描述预测误差，在相同评测条件下数值越小，误差通常越小；其他评分按结果中的说明阅读。

## 常见问题

没有图表时，先检查是否已经产生对应输出。结果暂时无法读取，可刷新后重新打开。图表提示只显示部分数据时，结合完整数据或下载文件查看。
