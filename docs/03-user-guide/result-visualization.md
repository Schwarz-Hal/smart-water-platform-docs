# 查看算法结果与评测

## 选择结果

工作流运行页默认展示最终结果，左侧可切换到某个节点。存在多个输出时选择所需报告或时序；右侧不再重复展示同一份数据。任务执行状态与结果读取分别更新，结果暂时读取失败不代表算法执行失败。

结果区域提供可视化、数据明细和运行依据。参数、精确版本、来源及原始数据按需查看。快速试用中的异常与预测使用同一套展示规则。

## 异常检测

观察曲线上的异常标记，再查看对应时间的分数和阈值。图例可以切换显示，时间窗口支持缩放与复位。预热范围留空，不计入正常点；异常片段由标签连续性组织时不代表已经确认漏损。

分数不一定是概率，不同算法原始分数不能直接比较。训练范围内回顾分析应与后续时段检测分开理解。历史结果缺少输入观测时仍可查看分数，不会使用文件最新版本代替原输入。

## 预测与评测

历史与预测在预测起点处分开；预测区间仅在算法实际提供时显示。MSE、MAE、RMSE需要真实对照，越低通常表示该评测范围内误差越小，不代表所有时段效果更好。

比较不同运行前，先确认数据版本、指标单位、预测长度、评测范围和样本数一致。没有真实标签时，异常数量不能代替准确率。训练loss与预测误差分别查看。

## 治理、质量及其他输出

治理结果支持处理前后对比、变更记录与未解决问题。质量视图保留分项及评估范围；未评估不显示为零分。表格、候选事件、文件和模型引用采用对应的明细或资源卡，未知结构可逐层展开。

图表显示的抽样范围与完整报告不同；有抽样或截断提示时，应结合完整数据查看。显示失败可重新读取结果，不必重新执行算法。
