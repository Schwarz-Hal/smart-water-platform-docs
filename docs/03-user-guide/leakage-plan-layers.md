# 管网漏损闭环方案与图层

## 用途与前置条件

在快速试用的“管网漏损闭环”中，可先选择分析日期，再逐步设置本次分析采用的方法和参数。管网图及其显示开关与分析方案分别管理：隐藏一类资产只影响观看，不会从计算中删除数据。

访客可查看公开场景、拓扑和执行方案目录。执行分析需要登录，并具有工作流运行权限；选择下文的学习型方法时还需要算法训练权限。当前场景需有可用的整理数据包；这不是任意上传文件后自动完成水力建模的入口。

## 配置八个阶段

点击阶段查看“运行前配置”，调整选项后再运行。阶段可恢复默认参数；方法改变时只显示相应参数。执行期间不修改正在运行的方案，结果中的参数来自提交时的快照。

| 阶段 | 可设置内容 | 使用说明 |
| --- | --- | --- |
| 数据接入 | 查看当前场景，日期由上方窗口设置 | 必需步骤，不能关闭；基础输入校验始终执行 |
| 质量检查 | 是否执行、最低质量分 | 给出是否达到质量分要求；低于要求不等于后续计算自动中断 |
| 数据治理 | 不处理、线性、PCHIP、Kalman、SAITS；缺口长度；异常标记 | 只填补符合条件的缺失位置，不替换已存在的观测峰值；SAITS自动预训练 |
| 基线分析 | 历史同刻中位数、上一周期基线、DLinear、PatchTSMixer、PatchTST | 统计基线与学习预测的使用范围见下文 |
| 异常识别 | EWMA／CUSUM、稳健残差、季节稳健、Isolation Forest、BeatGAN、TranAD | 新方法自动建立参考模型，不代表得到已确认漏点 |
| 夜间流量与水量平衡 | 夜间起止小时 | 结束小时必须大于开始小时，不支持跨午夜窗口 |
| 候选管段 | 最多显示数量、最低证据置信字段 | 用于筛选已有拓扑代理候选，不是现场验证的漏损概率 |
| 处置建议 | 是否执行 | 生成复核建议，不执行泵阀控制或水力调节仿真 |

可选阶段通过“执行此步骤”关闭。异常识别依赖日内基线，候选管段依赖异常识别，处置建议依赖候选管段。关闭前置步骤后，应同时关闭依赖它的步骤；界面会指出不完整的组合。服务端将未执行或因依赖不可用的阶段标为“未执行”，不会显示为完成。

## 理解治理与检测结果

默认缺口上限为4个15分钟采样点。线性、PCHIP和Kalman只处理长度不超过上限、且两端存在观测的完整缺失段。更长的缺口及边界缺口保留缺失。选择“不处理”或关闭治理，原始缺失仍保留。

异常标记可使用Hampel阈值，但“仅标记”不会把峰值替换为零或插值。Kalman使用固定局部水平模型参数，不需要训练权重。修复值是估计值，不作为新测量证据。

EWMA／CUSUM使用有符号残差和可衰减累积量；缺失或预热位置没有有效分数。稳健残差方法按残差幅度判定。界面的分数用于该方案内的阈值展示，不能当作漏损概率，也不宜直接与其他模型的原始分数比较。

## 自动预训练与后台分析

选择SAITS、三种新增预测方法或四种新增检测方法后，一次“运行分析”会进入后台任务。无需先离开页面手工创建模型；系统会查找当前用户同一训练数据摘要、精确算法版本及参数的成功模型，有可用模型时复用，否则先预训练再分析。当前季节稳健、Isolation Forest和SAITS使用CPU，不因加入此流程而改为GPU算法。

默认设备为自动选择：支持CUDA的方法优先使用健康GPU。GPU忙时进入其队列等待，不因忙碌改用CPU；GPU不可用时自动模式选择CPU并显示原因。显式选择CUDA但没有可用环境会报错；已进入CUDA执行后发生错误不会再静默改用CPU重跑。

混合方案可在GPU Worker上运行，但其中CPU方法仍在CPU计算；每个模型记录实际训练设备，不能仅根据任务队列推断所有模型都使用GPU。

可配置训练轮数、输入窗口、滚动预测步数、训练比例和独立校准比例。默认使用前50%时段预训练、后续20%校准、最后30%评测；至少保留10%用于评测。实际训练从训练时段内选择满足长度要求的连续原始观测，缺测不会被删掉后拼成假连续序列。数据不足时任务给出失败信息，应增加有效历史或调整窗口。

SAITS对流量执行回顾性修复，压力保持原值。预测训练、预测上下文和误差评测仍使用原始观测，不把利用未来上下文修复出的值当作真实对照。预测上下文包含缺失时跳过该窗口，结果保留空值。预测误差报告显示MAE、RMSE和有效评测点数，不保证新增算法必然更准确。

学习型分析只在独立评测段显示异常分数。阈值对应50分：原始证据相对阈值的比值为1时得到50，约为2时得到66.7。该分数不是概率，不能和旧统计方案的百分制展示直接比较。训练、校准及预热位置不补成零。

界面每2秒读取任务状态，显示实际阶段、已有训练输出及设备；整体百分比仅表示阶段进度。关闭页面不会取消任务，地址中的 `leakage_run` 可用于恢复当前任务。取消后等待当前步骤的安全检查点确认，不能承诺立即中断。暂时读取失败会继续同步；最终成功以结果已保存且任务成功为准，失败时保留错误信息。

## 结果、修改与重启

运行完成后，阶段结果与本次提交的日期和方案对应。“本次执行配置”展示结果实际使用的只读快照，“下一次配置”用于编辑后续运行。改变草稿配置后，已有结果仍保留，需要重新分析才能得到新结果；修改显示图层不需要重跑。

方案快照由服务端保存。服务重启后，在数据包及方案快照仍存在的前提下，可按同一分析标识读取对应时间轴。学习型任务另保存结果和证据快照，仅创建者或管理员可查看。若提示方案或结果快照不可用，应检查备份或重新执行分析；不要用当前默认方案解释旧结果。

## 使用管网图例

资产类型依据数据中的显式类型字段分类，不按名称或编号猜测。图例只列出当前可渲染的数据类型及数量。节点按详情中的节点类型细分：远传表、机械表、三通、多通、一般管线点、管堵和泵站可分别显示或隐藏；未预设样式的非空类型也按原名称单列，不合并到“其他节点”。类型缺失的节点仍使用兜底分类。类别较多时可滚动图例列表。

| 资产 | 图例形状 |
| --- | --- |
| 连接点、其他节点 | 圆形，大小有区别 |
| 阀门 | 菱形 |
| 消火栓 | 三角形 |
| 计量点 | 方形 |
| 水泵 | 环形 |
| 水箱／水池 | 圆柱形 |

管段按记录管径分为不大于100 mm、大于100且不大于200 mm、大于200 mm、管径未记录四组。显示粗细是分组示意，不是严格比例的工程模型。

点击图例可隐藏或显示该类资产。隐藏资产不参与画布点击拾取，也不出现在搜索结果中；隐藏当前选中类别会清除选择。通过其他界面显式定位某个隐藏资产时，其类别会重新显示。可使用全部显示、透视／俯视和重置视角恢复观看范围。

分析图层可按所选分析量覆盖资产的基础颜色；形状仍表示资产类型，图例过滤仍只影响显示。

## 当前数据边界

本次可配置计算针对入口总表15分钟流量、压力时序。节点日级数据和管段拓扑代理层仍沿用其已有计算口径；修改总表基线或检测参数，不表示全管网每个节点都执行了同样的15分钟算法。

拓扑支持查看关联信息，但缺少逐管实测时，候选管段仍是拓扑代理证据。当前闭环不提供泵阀控制，也不将图层变化解释为水力模拟结果。Chronos-Bolt尚未纳入本闭环选择，因为没有就绪的本地权重。

开发者离线模式可查看方案目录和配置界面，但不支持配置方案的真实执行；提交时明确提示不支持，不使用样例结果冒充本次计算。

部署进度、实际GPU验收和验证范围以维护与发布记录为准。功能说明不作为运行环境或算法效果已验收的证明。
