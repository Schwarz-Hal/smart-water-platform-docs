# CSV 上传、预览、字段映射与导入

## 用途

把本地监测 CSV 变成可选择的数据资产。原始文件由平台保留，导入完成后可以在数据资产页面选择生成的版本。

## 前置条件与角色

需要已启用账号和数据导入权限。准备非空 `.csv` 文件；页面标示最大 200 MB，支持 UTF-8、UTF-8 BOM 和 GB18030。文件应包含点位、时间和至少一个指标列，记录 ID 列可选。

## 操作步骤

1. 打开【数据源与导入】，在页面的 CSV 区域填写【数据资产名称】，选择文件并点击【上传并预览】。
2. 在同页【字段预览与映射】中核对编码、表头和样例行；如果表头重复、内容为空或乱码，点击【重新选择文件】并先修正文件。
3. 选择【点位列】和【时间列】，按指标填写【指标代码】、【显示名称】、【单位】和【原始值列】；修复值列、状态列按实际数据填写。需要导入后自动评分时，保留【导入完成后自动质量评分】勾选。
4. 点击【确认映射并导入】，在页面的接入记录中等待导入任务和数据资产版本可用。

## 结果与失败处理

导入完成后，资产出现在【可用数据资产】中，可继续打开资产详情。页面提示列不存在、重复映射、超限或编码不支持时，返回上传/映射流程修正文件或映射；相同内容再次上传不会覆盖已有资产，只会提示可能存在重复内容。任务失败时先查看接入记录或任务详情中的错误，再按情况重新打开上传/导入流程，不要假定任务中心的【重新运行】一定会重新提交原映射。

## 开发联调

页面行为与接口字段的对应关系见开发文档中的数据资产 API；普通用户不需要接触接口路径或批次标识。
