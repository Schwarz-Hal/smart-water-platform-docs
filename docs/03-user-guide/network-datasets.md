# 管网数据集的构建、导入与读取

## 用途

管网数据集把拓扑节点、管段、测点、指标、观测和绑定关系组织为一个可追溯的 `.swnet` 数据包。SWNet 1.0 使用清单、原始来源副本和 Parquet 分片；按测点或时间范围读取时，无需把完整包加载到浏览器。

拓扑连接与观测覆盖是两件不同的事。具有节点坐标和连接关系，不代表该节点具有流量、压力或高频观测；不能把 500 个拓扑节点解释为 500 个节点都有完整高频测量。拓扑预览不是水力仿真，也不输出校准后的水力结果。

## 前置条件与角色

- 构建或导入需要 `data_file:write`；查询和导出需要 `data_file:read`，并通过对应文件的访问检查。管理员访问不取消来源完整性校验。
- 构建来源必须是已准备的 CSV、Parquet、JSON 或 GeoJSON 精确文件版本。必需来源为节点、管段和观测；测点与资产绑定表可选。
- 每个来源不超过 200 MB，来源合计不超过 600 MB；每个结构化来源最多 200 万行。一个包可选择 1–32 个指标，测点数与指标数的乘积不超过 20000。这些是实现上限，不是吞吐量或响应时间保证。
- 观测表每行对应一个测点和时间，可以有多个指标列。无时区时间必须声明来源时区；存储时间统一为 UTC，不改变观测频率。
- 准备节点和管段标识、管段起止节点、观测测点标识、时间列及指标列。坐标存在时声明坐标字段与 CRS；平台不猜测投影，也不按距离自动建立连接。

## 操作步骤

### 新建数据包

1. 在数据中心打开【管网数据集】，填写名称；在【选择输入】中选择节点、管段和观测的精确版本。可上传新文件，待解析完成后刷新并选择版本。
2. 在【拓扑与映射】确认字段。节点标识和管段标识必须唯一，管段端点必须引用已有节点。需要绑定观测时，提供明确的测点到节点或管段的关系；一个绑定测点只能对应一条绑定记录。
3. 在【时间与指标】选择时间和测点列，声明时区、指标编码、数值列、单位与来源类型。需要后续 C1 训练时，目标测点必须实际具有 `flow`、`pressure` 两个指标，不能用拓扑属性代替观测。
4. 在【绑定复核】确认配置。未绑定测点仍保留原始观测，并显示未映射数量；平台不会按名称、编号或空间距离猜测绑定。
5. 选择【确认并后台构建】。提交先创建任务和待就绪的输出版本，处理成功后才能读取包；状态以服务端任务为准。返回配置不会取消已启动任务。

构建冻结来源版本 ID 和 SHA256，并保存版本血缘。之后修改源文件的当前版本不会改变本次构建；构建不会原地修改来源文件。包保留来源副本、缺失值和原采样频率，不进行自动补零、重采样或观测合成。

### 导入和打开已有包

在【选择输入】使用【导入 .swnet】提交 SWNet 1.0 包。服务端校验清单版本、文件摘要、路径安全、必需表和引用关系，并从内容重新计算分片索引；导入完成前不能当作可用结果。

在【打开已有 SWNet 数据包】选择文件和精确包版本后打开。导入不是向原包追加观测；它生成独立的数据文件版本。其他压缩包或仅改扩展名的文件不构成有效 SWNet 包。

### 查看与导出

1. 查看节点、管段、测点、观测及未映射测点数量。拓扑预览依据已有坐标和连接关系展示，不证明传感器覆盖完整。
2. 在【按测点查看原频率时序】选择测点和指标；按需填写含时区的 ISO 起止时间，点击【读取时序】。
3. 检查时间、测点、指标、值和 `provenance`。界面每次最多显示 500 条，截断提示不表示后续数据不存在；缩小时间范围或导出完整数据包。空结果不会用零值替代。
4. 选择【导出 .swnet】下载便携包。公开清单和导出包不包含运行环境的对象存储引用；原始来源内容仍在包中，因此分享前须确认数据授权。

## 来源类型与使用边界

| `provenance` | 含义 |
| --- | --- |
| `observed` | 实测观测 |
| `synthetic` | 合成数据 |
| `cleaned` | 已清洗数据 |
| `estimated` | 估计数据 |
| `derived` | 派生数据 |
| `topology_proxy` | 拓扑代理数据，不是实测流量或压力 |

来源类型由构建配置明确声明并保留，不是平台替用户证明真实性。将数据用于训练前，确认采样周期、单位、缺失值和来源类型符合算法要求。SWNet 能保存不规则与缺失观测，不代表 [C1 单点训练](../05-algorithms/water-suite/c1-adaptive-anomaly.md) 能直接使用它们；需要处理时先执行显式治理，保留派生版本及其来源。

## 结果与失败处理

| 情况 | 处理方式 |
| --- | --- |
| 来源正在解析或格式不支持 | 等待完成，或选择已准备的受支持版本 |
| 管段端点、绑定资产不存在或 ID 重复 | 检查标识与字段映射，不以自动匹配替代修正 |
| 缺少时间时区或指标声明 | 补充来源时区、指标编码和数值列；不要假定单位转换已经执行 |
| 来源摘要或包摘要不匹配 | 停止使用该结果，重新确认来源或重新取得完整包 |
| 构建失败 | 查看任务错误码，修正配置后重新提交；待处理/失败包不是可训练输入 |
| 无对应时段观测 | 核对测点、指标和时间范围；缺测不等于零，也不等于正常 |

本页说明实现行为，不宣称服务器部署、生产规模验收或模型效果已经通过。
