# 统一数据资源

## 用途

统一数据资源把已上传文件中的拓扑、点位时序或显式映射整理为可复用的版本化资源。拓扑、时序和映射可以分别创建；一个数据集可以包含多类资料，也可以在权限允许时组合不同数据集的来源。

本功能不会把没有边的点位集合伪造成管网，也不会因为预览只显示少量记录而限制实际工作流读取范围。资源创建、追加和读取均保留来源文件版本、摘要和行级来源信息。

## 前置条件与角色

需要登录，并按平台已有权限访问来源文件和所属集合。创建或追加资源需要相应的数据文件写入权限；查看资源、点位目录、拓扑和时序需要相应的数据文件读取权限。跨集合组合时，每个来源分别检查权限；看见场景或资源不代表自动获得全部来源权限。

资源当前支持来源格式：CSV、Parquet、JSON 和 GeoJSON。每个来源最大 512 MiB，所有来源合计最大 2 GiB，一次请求最多 100 个来源；超限会在预检或构建阶段拒绝。

## 自动创建时序资源

从数据资源页选择“自动创建时序”，从已有结构化文件中选择当前文件版本。页面只读取该版本已经保存的字段 `schema`、时间画像和最多 50 行预览，给出常见宽表（每列一个指标）或长表（指标名称列＋数值列）的建议；此步骤不会重新读取全文件，也不会创建资源。

识别结果显示时间列和点位候选、指标列、单位证据、时间画像摘要及警告。时间列有歧义或日期格式不明确时需要确认；已有时区假设应核对。没有证据时不默认单位或时区，未知本地时区可以留空以创建仅供预览的资源；Excel 日期序号必须指定时区。没有点位候选时默认使用本文件独立点位标识，仍可在微调中修改；出现多个点位候选时需选择或确认，系统不会猜测分组。

识别需要 `data_file:read`。来源版本必须是可读取的结构化文件；复用已有资源版本时还要能读取被复用的资源。

## 微调并创建

1. 核对资源名称、时间列、点位列或内部点位标识，以及宽表/长表形式。
2. 宽表选择一个或多个指标并可修改指标名、单位、通道和数值口径；长表选择指标名称列、数值列及可选的单位列、通道列。长表通道列受自动流程支持；宽表按行的通道、质量或时区列不会被自动追加复用。
3. 需要时指定 `time_format`（例如 `unix_seconds`、`unix_milliseconds`、`excel_serial_date` 或受支持的明确日期格式）和时区。Excel 日期序号必须提供时区。
4. 在“样本预览”按点位和单个指标查看最多 50 行及曲线；不同单位不会混在同一条预览曲线中。
5. 点击创建。请求直接创建后台完整验证任务，不另设独立的手动预检步骤；任务完成后才发布新版本，原始文件和来源版本不被改写。新资源默认无归属，可在资源/数据集管理中后续移动。

同一来源的多个指标在一次构建中扫描；不同单位仍保持独立指标，不自动转换。数值字符串按构建规则标准化，空白值变为 `null`，同时保留 `raw_value`；不会填零、静默去重或修复冲突。

## 证据与限制

识别建议的证据范围固定为 `stored_schema_and_preview`。`sample_count` 是样本行数，`row_count` 是文件记录数（可能未知）；`full_validation: false` 表示尚未完成全量检查。样本可展示不代表全量可计算：后台任务会读取完整来源并检查字段、时间、数值、点位、单位和版本摘要。

点位、时间、单位和通道建议均可修改；缺证据时不补单位或时区。单位转换、数据治理、自动补值、去重和一键组网不在本批范围。拓扑映射高级界面保留，未由自动时序流程重做。

## 创建资源

1. 选择资源类型：`topology`（拓扑）、`timeseries`（点位时序）或 `mapping`（映射）。
2. 选择一个或多个已有文件版本，填写来源角色和字段映射。字段映射是“规范字段→来源列名”；固定值只能是标量，不是表达式。
3. 需要时在高级流程运行创建预检，查看错误、警告、来源摘要、记录数量和适用性。
4. 预检通过后提交构建任务，等待任务变为成功。构建成功才发布新的资源版本并切换当前版本；失败或取消不会切换当前版本。

### 必需字段

| 资源 | 必需字段 | 可选信息 |
| --- | --- | --- |
| 拓扑 | 节点 `node_id`；管段 `edge_id`、`source`、`target` | `node_type`、`x`、`y` |
| 点位时序 | `point_id`、`metric`、`timestamp`、`value` | `channel`、`unit`、`timezone`、`quality`、`statistic` |
| 映射 | `point_id`、`metric`、`channel`、`target_id`、`target_kind` | `role`、有效期、`confirmed`；还必须引用拓扑和时序版本 |

拓扑坐标可以缺失，但真实连接必须由节点和边提供；缺少坐标只限制空间显示，不自动阻止图结构读取。映射目标可以是节点或边，系统不按距离或邻接关系自动猜测映射。

## 查看和读取

资源详情显示精确版本、来源摘要、记录数量、适用性和配置。可以分页查看点位目录、拓扑节点/边和映射，也可以按点位、指标、通道和时间范围读取时序，或读取指定时间切片。

页面预览是有界展示，不代表完整资源。工作流读取使用选择的版本和点位/指标/时间范围，并按分区读取；不会先加载全量数据再截取，也不会用 50 行预览代替实际运行。单次执行有明确的读取上限，超过上限会失败而不是静默截断。

原始时间和值、空值、零值、重复观测、质量标记及来源信息继续保留。非数值内容可以保留用于预览，但不适用于需要数值的计算；非有限数值使用明确标记，不改写成普通空值。

### 单位和时区

单位或时区未知时，资源仍可保存和预览，但相关计算会显示为不适用。本批仅保存和检查单位，不自动进行单位转换；源值、源时间和来源版本仍可追溯。无时区的本地时间可先留空创建预览资源，运行相关计算前需要资源配置提供时区；存在夏令时歧义时需要明确偏移量。

## 追加新版本

在资源详情中提交追加请求时，需要指定当前基准版本和新增来源。若原版本保存了单一来源且字段类型兼容，识别页面可沿用可由简化表单往返的规则并要求核对新增文件；多来源、规则缺失或类型不兼容时不会自动复用，需微调映射。包含宽表按行通道、质量或时区列等复杂规则时，使用资源页的“高级追加”按钮，不会静默丢弃字段。系统检查新增时间范围、字段/单位/点位兼容性、重复和冲突，并生成新的不可变版本。原版本和原始文件不被覆盖。

同一 `point_id + metric + channel + timestamp` 出现不同数值时，本批安全策略是阻止发布。完全相同的重复观测仍可追溯，不静默删除。并发追加若基准当前版本已变化，会因版本冲突拒绝，避免后一次追加覆盖前一次结果。

## 在工作流和场景中使用

资源选择绑定精确版本、资源类型及点位/指标/通道/时间范围。本批数据资源输入适配仅面向工作流的 `series`/`table` 输入，不宣称拓扑或映射已适配任意算法。工作流节点通过统一读取接口取得规范观测记录，不直接读取固定目录。运行提交后会冻结资源版本、选择和来源摘要；后续追加不会改变已提交运行。

没有拓扑的时序仍可以供明确不依赖拓扑的流程使用；声明为必需的拓扑、映射、指标或其他输入缺失时，适用性检查应阻止对应运行，不静默跳过必需输入。当前文档不将资源功能表述为完整漏损算法、自动调度或人工确认报告。

## 失败处理

| 情况 | 处理 |
| --- | --- |
| 来源格式不支持、大小超限或来源内容变化 | 修正来源后重新预检；原文件版本不被改写 |
| 必需字段缺失、资源为空或拓扑端点不存在 | 按错误详情修正映射或来源，再提交新的构建 |
| 单位/时区缺失 | 可保留预览；补充明确语义后再运行相关计算 |
| 任务失败或取消 | 查看任务状态和错误，安全重试；当前版本不会切换 |
| 追加出现数值冲突或基准版本过期 | 保留原版本，重新读取当前版本并按确认策略处理 |
| 刷新或短暂断网 | 通过任务状态重新打开构建/追加结果；不要重复提交不同请求标识 |

自动识别失败不会创建不完整资源。来源版本不可访问、文件未解析或识别请求过期时，重新选择可访问的版本并重新识别；未提交的微调不会被后台保存。

资源 API 不返回对象存储地址、对象键或凭据。资源上传成功、解析成功、适用于某项计算和工作流运行成功是不同状态，不能互相替代。
